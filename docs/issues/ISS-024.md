## 现象

数据库视图筛选面板中的下拉菜单（列名选择、操作符选择、值选择）使用了浏览器原生 `<select>` 元素，样式与项目整体设计风格不搭配。

## 复现路径

1. 打开任意数据库视图
2. 点击筛选按钮，添加筛选条件
3. 查看列名、操作符、值的下拉选择器——与项目其他 UI 风格不一致

## 期望行为

使用自定义样式的下拉组件，与项目现有 UI（如列头菜单、选项管理弹窗）风格一致，不使用浏览器原生控件。

## 根因待查

待排查筛选面板实现位置，确认 `<select>` 分布范围后制定替换方案。
