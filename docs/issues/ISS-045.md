# ISS-045 — 按钮块设置面板「确定」按钮点击无响应

| 字段 | 内容 |

| 状态 | 已修复 |

## 现象

在按钮块设置面板中选择动作类型（如「新建子页面」）后，点击「确定」按钮无任何响应，设置不保存，面板不关闭。

## 根因假设

与 ISS-040/044 同类：设置面板通过原生 `mousedown` + `stopPropagation()` 阻断事件冒泡，面板内「确定」按钮若依赖 React 合成 `onClick` 则无法触发。参照 ISS-044 修复经验（面板内子组件改用 `onClick`），「确定」按钮可能同样受影响。

## 待确认

- 面板内「确定」按钮使用 React `onClick` 还是原生 `mousedown`？
- `commitPanel` 函数是否被正确调用？
