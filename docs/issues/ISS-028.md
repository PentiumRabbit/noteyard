# ISS-028 — 数据库视图白屏（缺少 Error Boundary）

## 现象

点击任意数据库视图页面后整个页面白屏，无法操作。

## 根因

ISS-026（commit `40a91ed`）在 `DatabaseView.tsx` 中引入了 `useSensors(useSensor(PointerSensor, ...))` Hook 调用，但错误地将其放置在 `if (!db) return <div>加载中…</div>` 之后（原第 659 行）。

这违反了 React 的 **Rules of Hooks**：Hook 不能在条件语句或 early return 之后调用。

- 首次渲染时 `db` 为 null，组件在第 629 行 early return，该 Hook 未被调用
- 数据加载后 `db` 有值，组件完整渲染，Hook 被调用
- React 检测到两次渲染 Hook 调用数量不一致，抛出 `Uncaught Error: Rendered more hooks than during the previous render`
- 没有 Error Boundary 兜底，异常传播至根，整棵组件树卸载 → 全页白屏

## 期望行为

1. DatabaseView 组件内部报错应被 Error Boundary 捕获，只降级展示该组件区域的错误提示，不影响页面其他部分
2. 同时排查并修复导致 DatabaseView 抛出异常的根因

## 修复方案

### T1 — Hook 顺序修复（commit `a1c4f70`）

将 `tableDndSensors = useSensors(...)` 从 early return 之后（原第 659 行）移至 `useRef` 声明区下方（第 138 行），确保每次渲染 Hook 调用顺序一致。

涉及文件：`web/src/components/database/DatabaseView.tsx`

### T2 — Error Boundary 兜底（commit `aab842e`）

新建 `DatabaseViewErrorBoundary.tsx`（React class component，实现 `getDerivedStateFromError` + `componentDidCatch`），在 `Editor.tsx` 中替换 `DatabaseView` 使用。

数据库视图内部异常将被捕获，降级显示区域错误提示（含"重新加载"按钮），不影响页面其他部分。

涉及文件：
- `web/src/components/database/DatabaseViewErrorBoundary.tsx`（新建）
- `web/src/components/editor/Editor.tsx`（改用 DatabaseViewErrorBoundary）
