# ISS-041 — 按钮块右侧设置图标点击无响应

## 现象

点击按钮块右侧的设置图标（⚙）后，面板不弹出，无任何响应。

## 背景

ISS-040 修复了设置面板内输入框无法聚焦的问题（native addEventListener 拦截 mousedown）。
本次问题为：⚙ 图标点击本身无响应，面板根本未打开。

## 根因

与 ISS-040 相同：ProseMirror 在 `view.dom` 注册原生 `mousedown` 监听器并调用
`stopPropagation()`，事件无法冒泡到 `document`，React 合成事件委托系统从未收到，
⚙ 按钮的 `onMouseDown` 因此永远不触发。

ISS-040 修复了面板 div 内的 mousedown，但未修复触发面板打开的 ⚙ 按钮本身。

## 修复

- `web/src/components/editor/Editor.tsx`：添加 `settingsBtnRef`，通过 `useEffect + addEventListener` 在 ⚙ 按钮上注册原生 `mousedown` 处理器，在 ProseMirror handler 之前截获事件。
- 同步修复 outside-click 守卫，排除 settingsBtnRef 自身点击，防止面板关闭后被立即重开。
