# ISS-014 — 拖动并排功能失效

| 字段 | 内容 |
|------|------|
| ID | ISS-014 |
| 发现时间 | 2026-05-03 |
| 发现来源 | 用户反馈 |
| 状态 | 已修复 |
| 优先级 | P1 |

## 现象

在编辑器中，将一个块拖动到另一个块的左侧或右侧边缘时，无法自动合并为两列（并排）布局。拖动后块仍保持上下排列，不生成 `columnList`。

## 复现步骤

1. 打开任意页面，创建至少两个段落块
2. 拖动其中一个块到另一个块的左侧或右侧边缘
3. 释放鼠标

## 预期结果

两个块合并为 `columnList`，形成左右并排布局。

## 实际结果

块仅移动位置（上下排列），不生成并排列。

## 初步分析

编辑器使用 `@blocknote/xl-multi-column` 0.26.0 实现并排功能，通过 `useCreateBlockNote` 的 `dropCursor: multiColumnDropCursor` 选项注册。

需要排查：
1. `multiColumnDropCursor` 是否正确接收 `editor` 参数（BlockNote 0.26 API 可能有变化）
2. `withMultiColumn` schema 包装是否影响 drop 行为
3. 是否存在其他 dragover 监听器阻止了默认行为

## 修复记录

**根本原因**：`multiColumnDropCursor` 签名为 `(options: DropCursorOptions & { editor }) => Plugin`，BlockNote 调用时传入 `{ width, color, editor }`，参数匹配正确。真正缺失的是 `SideMenuController` 未注册，导致块拖拽句柄不可用，`handleDrop` 无法触发。

**修复方案**：
1. `dropCursor: multiColumnDropCursor` 调用方式确认正确（T03）
2. 在 `BlockNoteView` 内注册 `<SideMenuController />`，恢复块拖拽句柄（ISS-030）
