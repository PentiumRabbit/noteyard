## 现象

打开含多列布局（columnList）的页面时，控制台报错：

```
[Editor] replaceBlocks failed RangeError: Invalid content for node column: <>
```

页面内容无法加载，只剩标题，正文全部丢失。

## 根因

`toBlockNote.ts` 中反序列化 `columnList` 时，若某个 `column` 子块在数据库中没有子行（colChildren 为空数组），
BlockNote ProseMirror schema 要求 column 节点 content 为 `+`（至少一个子节点），传入空数组导致 `createChecked` 抛 RangeError，
整个 `replaceBlocks` 失败，编辑器回退到空状态。

旧格式 `columns` 降级分支同样存在此问题。

## 修复方案

`colChildren` 为空时补一个空段落占位块，保证 column 节点始终有至少一个子节点。

## 修复确认

修复已在 `web/src/utils/toBlockNote.ts` 中落地（`safeChildren` 逻辑，第 26-28 行）：

```ts
const safeChildren = colChildren.length > 0
  ? colChildren
  : [{ id: `${col.id}-placeholder`, type: BLOCK_TYPES.PARAGRAPH, props: {}, content: [], children: [] }];
```

经 REQ-079 T01 验证，逻辑正确有效，修复版本 v0.1.19。
