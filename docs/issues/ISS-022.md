# ISS-022 — 数据库列设置面板「编辑公式」等操作项顺序不合理

| 字段 | 内容 |
|------|------|
| ID | ISS-022 |
| 状态 | 待修复 |
| 优先级 | P3 |
| 发现日期 | 2026-05-04 |
| 发现人 | 用户 |

## 现象

列头设置面板中，「编辑公式」等操作项排在类型选择的下方，用户希望高频操作项（如编辑公式）排在类型选择的上方，其他操作项也做类似调整。

## 期望顺序（参考）

1. 列名编辑
2. 编辑公式（或其他高频操作）
3. 类型选择
4. 其他操作（删除等）

## 当前顺序

类型选择在编辑公式上方，与用户操作习惯不符。
