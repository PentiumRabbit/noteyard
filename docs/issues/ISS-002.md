# ISS-002: formula 自引用循环检测漏洞

| 字段 | 内容 |
|------|------|
| Issue ID | ISS-002 |
| 严重程度 | P2 |
| 状态 | ✅ 已修复 |
| 发现于 | REQ-028 TE 验收 TC-04 |
| 修复 commit | `a548ce8` |

**根因**：`checkFormulaLoop` 从数据库读取已有列构建 `colByName`，但新建列尚未入库，自身名字不在映射中，DFS 跳过自引用，导致 `{自身}+1` 类公式未被拦截。

**修复**：增加 `colName` 参数，调用前手动注入 `colByName[colName]=colID`。
