# ISS-003: database 块 flush 覆盖空 databaseId

| 字段 | 内容 |
|------|------|
| Issue ID | ISS-003 |
| 严重程度 | P2 |
| 状态 | ✅ 已修复 |
| 发现于 | REQ-029 交付后，TE 验收页打开无内容 |
| 修复 commit | 待补 |

**根因**：`buildDtos` 对 database 块无条件把 `b.props` 序列化写回后端。当页面首次加载时 BlockNote 内存中 `databaseId` 为空（旧数据），编辑器心跳或 flush 触发后把 `{"databaseId":""}` 覆盖了后端正确的 content，导致页面再次加载时 `databaseId` 为空，DatabaseView 不渲染。

**修复**：`buildDtos` 对 database 块增加保护——`databaseId` 为空时跳过 flush，不写回后端。
