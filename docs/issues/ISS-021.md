# ISS-021 — 数据库列头类型选择面板内容过长无法完整展示

| 字段 | 内容 |
|------|------|
| ID | ISS-021 |
| 状态 | 待修复 |
| 优先级 | P2 |
| 发现日期 | 2026-05-04 |
| 发现人 | 用户 |

## 现象

点击列头弹出的列设置面板，类型选择列表内容过长，在可视区域内展示不开，需要滚动才能看到全部选项。

## 复现步骤

1. 打开含数据库块的页面
2. 点击任意列头，弹出列设置面板
3. 观察类型选择区域

## 预期行为

类型选项完整可见，或面板高度自适应并在可视区域内正常展示（不需要滚动）。

## 实际行为

类型列表被截断，需要滚动才能看到所有类型选项。
