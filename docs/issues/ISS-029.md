## 现象

ISS-028 只为 DatabaseView 补充了 Error Boundary。其他主要组件（Editor、KanbanView、页面列表等）若内部抛出未捕获异常，仍会导致整页白屏。

## 期望行为

所有主要组件均有 Error Boundary 兜底，组件内部报错只降级展示该组件区域的错误提示（含"重新加载"按钮），不影响页面其他部分。

## 实现要点

1. 梳理需要加 Error Boundary 的组件范围（Editor、KanbanView 等页面级/视图级组件）
2. 复用 ISS-028 中已有的 `DatabaseViewErrorBoundary` 模式，或抽取通用 `ErrorBoundary` 组件统一复用
3. 在 `Editor.tsx` 或路由入口处统一包裹，避免每个组件重复包裹

## 修复方案（commit `11dd9ab`）

新建 `web/src/components/ErrorBoundary.tsx`，通用 class component，支持 `children` 和可选 `fallbackTitle`。

`DatabaseViewErrorBoundary` 改为轻量包装，底层委托给 `ErrorBoundary`（向后兼容）。

`App.tsx` 统一包裹：
- `Sidebar` → `<ErrorBoundary fallbackTitle="侧边栏加载失败">`
- `SettingsPage` → `<ErrorBoundary fallbackTitle="设置页加载失败">`
- `Editor`（两处）→ `<ErrorBoundary fallbackTitle="编辑器加载失败">`
