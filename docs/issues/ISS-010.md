# ISS-010: 应用内无默认使用说明/引导内容

## 状态
已修复

## 优先级
P2

## 现象
首次打开应用，侧边栏和编辑区为空，用户不知道如何开始使用。没有任何引导页、欢迎页或示例内容。

## 复现步骤
1. 全新安装或清空数据后启动 noteyard
2. 观察主界面

## 预期
应有默认的欢迎页面或示例笔记，帮助用户了解基本操作（创建页面、使用块编辑器、数据库等）

## 实际
空白界面，无任何内容或引导

## 报告人
总负责人

## 根因分析（总架构师）

后端 `Open()` 函数在数据库迁移后没有任何种子数据逻辑。`schema_migrations` 框架
已支持事务型版本化迁移，是插入种子数据的天然位置。

**实现方案**：在 `server/internal/db/seed.go` 中新增 `WelcomeSeedMigration`
（版本 2），注册到 `Migrations` 切片。迁移函数首先检查 `pages` 表行数：
- 若为 0（新库）：插入欢迎页面 + 16 个块内容（标题、段落、列表）
- 若非 0（已有数据）：直接返回，不覆盖用户内容

所有内容块使用标准 BlockNote InlineContent[] 格式，与前端 `toBlockNote` 解析逻辑完全兼容。

**测试影响**：`page_repo_test.go` 中 3 个测试使用 in-memory DB，会触发种子迁移，
导致页面计数断言失败。已将硬编码计数改为 baseline+N 模式，测试语义不变。

## 修复记录（工程师）

- 新增 `server/internal/db/seed.go`：`WelcomeSeedMigration` (schema_migrations v2)
- 页面 ID 固定为 `00000000-0000-0000-0000-000000000001`，避免重复插入
- 16 个块覆盖：H1 标题、引导段落、H2 x4（创建页面/块编辑器/数据库/更多功能）、列表项 x9、斜体结束段
- 更新 `page_repo_test.go` 3 处计数断言，改为 baseline 相对计数
- `go test ./...` 全部通过，`tsc --noEmit` 无报错
