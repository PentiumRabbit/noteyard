# ISS-044 — 按钮块动作下拉列表选项无法选择

## 现象

按钮块设置面板中，点击「动作」下拉列表后弹出选项列表，但列表中的选项（如「无」「打开链接」「新建子页面」「编辑页面属性」）点击后无响应，无法切换动作类型。

## 背景

REQ-083 新增了 `new_subpage` 和 `edit_page_props` 两个动作选项。ISS-040/041 修复了面板内输入框和 ⚙ 按钮的原生 mousedown 拦截问题，但动作下拉列表的选项点击是否经过同样的处理尚不明确。

## 根因假设

与 ISS-040/041 同类问题：ProseMirror 在 `view.dom` 上注册原生 `mousedown` 并调用 `stopPropagation()`，导致 React 合成事件（`onClick`/`onMouseDown`）无法触发。动作下拉选项若依赖 React 合成事件响应点击，则会无响应。

## 待确认

- 动作下拉选项当前使用 React `onClick` 还是原生 `mousedown`？
- 面板的 `panelRef` mousedown 阻断是否覆盖了选项列表区域？
