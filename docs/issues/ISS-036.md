# ISS-036 — 文件附件块样式前端截断

| 字段 | 内容 |
|------|------|
| ID | ISS-036 |
| 状态 | 已修复 |
| 优先级 | P2 |
| 发现日期 | 2026-05-05 |
| 发现人 | 用户 |

## 现象

上传文件后，编辑器中显示的文件附件块（file-attach-block）样式不完整，前面内容被截断，图标或文件名开头不可见。

## 需要排查

1. 检查 `.file-attach-block` CSS，是否有 `overflow: hidden` + 宽度限制导致前端截断
2. 检查 `FileAttachBlock` 组件渲染结构，icon/name 是否在 flex 容器内被挤压
3. 检查父容器（BlockNote block container）是否有宽度或 padding 限制
