## 现象

v0.1.11 生产包安装后，打开/新建任意页面报 "Load failed"，数据无法加载。dev 模式（`tauri dev`）正常。

## 根因

Go sidecar CORS 配置 `AllowedOrigins` 只包含 Vite dev server 的域名：

```go
AllowedOrigins: []string{
    "http://localhost:5173",
    "http://localhost:5174",
    "http://localhost:3000",
}
```

Tauri v2 生产打包后，WebView 从内嵌资源加载页面，其 origin 为 `tauri://localhost`（macOS），不在白名单中。所有 fetch 请求被浏览器的 CORS 策略拒绝，WebKit 报 "Load failed"。

dev 模式下 `devUrl = http://localhost:5173`，origin 在白名单里，所以开发时没有复现。

## 修复

`server/cmd/main.go` CORS 白名单加入 `tauri://localhost`：

```go
AllowedOrigins: []string{
    "http://localhost:5173",
    "http://localhost:5174",
    "http://localhost:3000",
    "tauri://localhost",    // Tauri v2 生产 WebView origin (macOS/Linux)
}
```

## 备注

Windows 的 Tauri WebView origin 是 `https://tauri.localhost`，如需支持 Windows，还需加入该域名（当前未验证，待 Windows 测试时补充）。
