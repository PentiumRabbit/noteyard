# ISS-005 下拉菜单靠近底部时显示不全

| 字段 | 内容 |
|------|------|
| ISS ID | ISS-005 |
| 状态 | 待修复 |
| 日期 | 2026-05-02 |
| 优先级 | P2 |
| 来源 | 用户反馈 |

## 现象

noteyard 应用中所有下拉菜单（select 列单元格选项、新增列类型选择、关联列目标数据库选择、汇总列配置弹窗等），
当触发位置靠近页面底部时，菜单向下展开被裁切，内容显示不全。

## 根因

下拉菜单使用绝对定位向下展开（`top: 100%`），未检测视口边界，靠近底部时溢出被 `overflow: hidden` 或视口裁切。

## 修复方案

检测菜单展开后是否超出视口底部，若超出则改为向上展开（`bottom: 100%` 替代 `top: 100%`）。
需排查所有自定义下拉组件的定位逻辑。
