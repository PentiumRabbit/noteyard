# ISS-020 — 数据库视图列名弹窗首次位置异常

| 字段 | 内容 |
|------|------|
| ID | ISS-020 |
| 状态 | 待修复 |
| 优先级 | P2 |
| 发现日期 | 2026-05-04 |
| 发现人 | 用户 |

## 现象

数据库视图中，点击「添加列」或编辑列名时弹出的输入弹窗，**第一次显示位置异常**（偏移错误），再次点击后位置恢复正常。

## 复现步骤

1. 打开含数据库块的页面
2. 点击「添加列」或列头触发列名编辑弹窗
3. 第一次弹出时观察弹窗位置

## 预期行为

弹窗每次都紧贴触发元素正确定位。

## 实际行为

第一次弹出时位置偏移，第二次起恢复正常（可能是首次未获取到正确的触发元素位置）。
