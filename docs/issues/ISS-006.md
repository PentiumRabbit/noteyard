# ISS-006 数据库非表格视图宽度被 BlockNote 容器限制

| 字段 | 内容 |
|------|------|
| ISS ID | ISS-006 |
| 状态 | 待修复 |
| 日期 | 2026-05-02 |
| 优先级 | P2 |
| 来源 | 用户反馈 |

## 现象

切换到看板、库、日历、列表、时间轴视图时，内容区域显示很窄，不能充分利用可用宽度。

## 根因

`DatabaseView` 组件渲染在 BlockNote 编辑器的内容节点（`contentEditable={false}` 的 `db-wrap` div）内，
受 BlockNote 编辑器内容列宽约束（通常有 `max-width` 限制）。

表格视图因为有横向滚动（`db-scroll` + `overflow-x: auto`）勉强可用，
但看板（需要多列横排）、日历（需要 7 列网格）等视图没有突破外层宽度限制的机制，显示很窄。

## 修复方案

给 `.db-wrap` 在非表格视图时加 `width: 100%`，同时检查 BlockNote 对自定义块节点宽度的限制，
必要时对 `db-wrap` 使用负 margin 或 `position` 技巧突破编辑器内容列宽。
