# ISS-046 — 按钮块主按钮点击无响应（action=new_subpage）

## 现象

按钮块动作设置为「新建子页面」后，点击主按钮无任何响应：不创建子页面、不跳转、无可见副作用。

## 根因假设

REQ-083 T1 已将主按钮改为 `mainBtnRef` + 原生 `mousedown` handler，`new_subpage` 分支在 handler 内调用 `buttonBlockCtxRef.pageId`。可能原因：

1. `buttonBlockCtxRef.pageId` 未正确同步（Editor 组件 `pageId` prop 未传入或 ctxRef useEffect 未执行）
2. `api.pages.create` 调用失败（网络/权限问题）
3. `mainBtnRef` effect 中 `new_subpage` 分支逻辑本身有误

## 待确认

- `buttonBlockCtxRef.pageId` 在点击时是否有值？
- `mainBtnRef` mousedown handler 是否被触发（console.warn 是否出现）？
- `api.pages.create` 是否被调用？
