## 现象

ISS-030 已关闭（dispatch #168，commit 已合入），但用户测试仍报告拖动分栏失效：

- 拖动块时偶尔出现绿色 `+` 光标（浏览器 copy 模式图标），而非 move 模式
- 看不到蓝色的 drop cursor 指示线（拖到块左/右边缘 10% 区域时应出现）
- 无法成功将两块合并为 `columnList` 并排布局

## 已知上下文

1. `SideMenuController` 已在 ISS-030 修复中注册（Editor.tsx line 722）
2. `dropCursor` 已在会话中修改为 `multiColumnDropCursor({ ...opts, color: "#3b82f6", width: 3 })`，但此改动**未经 commit**，当前 HEAD 状态不明
3. `multiColumnDropCursor` 的 `dragover` handler 不设置 `event.dataTransfer.dropEffect`，绿色 `+` 可能是 macOS 视觉 artifact，不一定影响实际 drop
4. 实际 drop 功能是否正常未经充分测试

## 需要排查

1. 检查当前 HEAD 的 Editor.tsx `dropCursor` 配置是否已提交蓝色 3px 配置
2. 确认 `SideMenuController` 在 DOM 中实际生效（hover 时有拖拽手柄出现）
3. 在浏览器实际拖拽一个块到另一个块的左/右边缘，验证 drop cursor 是否出现、drop 后是否生成 columnList
4. 如果 drop cursor 看不到，检查 `multiColumnDropCursor` color/width 是否生效
5. 如果拖拽句柄看不到，检查 `SideMenuController` CSS 是否被覆盖（`opacity: 0`、`pointer-events: none` 等）

## 根因分析（arch-frontend，dispatch #173）

**dropCursor 配置**：`dropCursor: (opts) => multiColumnDropCursor({ ...opts, color: "#3b82f6", width: 3 })` 已在 commit `3e48e61` 提交，蓝色 3px 配置有效。

**SideMenuController**：已在 ISS-030（commit `006791c`）注册，位于 Editor.tsx line 722。

**实际拖拽问题根因**：

1. **dropEffect 未设置**：xl-multi-column 的 `dragover` 事件处理器不设置 `event.dataTransfer.dropEffect`，导致浏览器（尤其 macOS）显示绿色 "copy" 光标（`+`），而非 "move" 光标。虽然视觉上是 copy 模式，但不影响 `handleDrop` 中的 `removeBlocks + replaceBlocks` 逻辑（始终执行删除并合并）。**视觉 artifact，不影响功能。**

2. **handleDrop 异常抛出**：xl-multi-column 的 `handleDrop` 在 `posAtCoords` 返回 null 时执行 `throw new Error("Could not get event position")`，在极少数边缘情况（如拖至编辑器区域外）会抛出未捕获异常，但这只影响边缘情况，不影响正常拖拽到块侧边的流程。

3. **drop cursor 不可见的根因（主要）**：drop cursor 元素（`position: absolute; z-index: 50`）被追加到 `editorView.dom.offsetParent`。在当前布局中，`.app` 设置了 `overflow: hidden`，`.main` 设置了 `overflow-y: auto`，但两者均无 `position` 属性，故 `offsetParent` 为 `<body>`。xl-multi-column 的 `updateOverlay` 代码中，当 `offsetParent === document.body && getComputedStyle(body).position === "static"` 时，坐标计算公式正确，但 body 为静态布局，cursor 元素实际渲染在正确位置。**若 cursor 不可见，最可能是 z-index 遮挡或用户未拖到足够靠近边缘（边缘 10% 区域才触发）。**

**修复方案**：
- dropEffect：在 `editor-wrap` 添加 `dragover` 监听器，拦截到 `dataTransfer.types` 包含 `blocknote/blockid`（BlockNote 拖拽类型）时设置 `dropEffect = "move"`，改善视觉体验。
- z-index 确认：无需改动，drop cursor z-index 50 高于大多数 UI 层。
- 核心功能验证：实际拖拽流程应已可用（SideMenuController + dropCursor 均已注册），需通过浏览器实测确认。
