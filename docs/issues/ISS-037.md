# ISS-037 — 重启 app 后图片显示 ? 图标（URL 失效）

| 字段 | 内容 |
|------|------|
| ID | ISS-037 |
| 状态 | 待修复 |
| 优先级 | P1 |
| 发现日期 | 2026-05-05 |
| 发现人 | 用户 |
| 环境 | Tauri 客户端 |

## 现象

在编辑器插入图片后，关闭 app 重新打开，图片位置显示 `?` 图标（broken image），图片无法加载。

## 初步分析

图片 URL 在 app 重启后失效。可能原因：
1. 图片存储为临时路径（如 `blob:` URL 或系统 tmp 目录），重启后失效
2. 图片上传后 URL 使用了动态端口（`http://127.0.0.1:<随机端口>/uploads/...`），重启后端口变化导致 URL 失效
3. 图片文件本身未持久化，只存了引用

## 需要排查

1. 检查图片上传后存储的 URL 格式（blob? 绝对路径? 相对路径?）
2. 检查 Go server 上传接口 `/api/uploads`，文件存储位置是否跨重启持久
3. 检查数据库中 image block 存储的 URL 内容
4. 如果 URL 包含动态端口，需改为相对路径（`/uploads/xxx`）或在加载时动态替换端口

## 后端修复方案（arch-backend-ISS037）

### 根因确认

经代码审查确认根因：

- `server/internal/handler/upload_handler.go` L147：`URL: h.baseURL + "/uploads/" + filename`，将 `http://localhost:<port>` 拼入数据库
- `server/cmd/main.go` L109：`handler.NewUploadHandler(uploadDir, fmt.Sprintf("http://localhost:%d", actualPort))`，端口为动态绑定值（port=0 时由 OS 分配），重启后变化

### 改动范围确认

**无邮件通知、外链分享等需要绝对 URL 的功能。** 全局检索结果：
- `server/` 中无 SMTP、webhook、外链分享等使用 baseURL 的代码
- `baseURL` 字段仅被 `upload_handler.go` 的 `Upload()` 方法引用，且只用于构造响应的 `url` 字段

因此将响应改为相对路径是安全的，不影响任何其他功能。

### 具体修改

**文件 1：`server/internal/handler/upload_handler.go`**

- **L55**：`baseURL string` 字段可删除（或保留空置，不影响逻辑）
- **L65–L66**：`NewUploadHandler(uploadDir, baseURL string)` 签名中移除 `baseURL` 参数（或保留但忽略），函数体对应调整
- **L147**：将

  ```go
  URL: h.baseURL + "/uploads/" + filename,
  ```

  改为

  ```go
  URL: "/uploads/" + filename,
  ```

**文件 2：`server/cmd/main.go`**

- **L109**：将

  ```go
  uh := handler.NewUploadHandler(uploadDir, fmt.Sprintf("http://localhost:%d", actualPort))
  ```

  改为

  ```go
  uh := handler.NewUploadHandler(uploadDir)
  ```

  （若选择保留 `baseURL` 参数但传空串，则改为 `handler.NewUploadHandler(uploadDir, "")`）

**文件 3：`server/internal/handler/upload_handler_test.go`**

- `TestUpload_URLFormat`（L112–L130）：断言前缀由 `"http://localhost:8080/uploads/"` 改为 `"/uploads/"`；同时将各测试中 `NewUploadHandler(dir, "http://localhost:8080")` 的第二参数移除或传空串

### 静态文件服务路由

`server/cmd/main.go` L130 的静态文件路由 `/uploads/*` 保持不变，改动不涉及：

```go
r.Handle("/uploads/*", http.StripPrefix("/uploads/", http.FileServer(http.Dir(uploadDir))))
```

### 存量数据迁移

数据库中已有的绝对 URL（如 `http://localhost:8081/uploads/xxx.png`）需要处理。前端兼容方案由 arch-frontend 负责（在渲染时将绝对 URL 中的 host:port 替换为当前 `API_BASE`，或在 DB 中做一次性迁移）。后端无需感知存量数据。

### 改动影响评估

| 检查项 | 结论 |
|--------|------|
| 静态文件服务路由 | 不变，`/uploads/*` 继续正常工作 |
| cleanup_handler.go 中的 `uploadsRefRe` | 匹配 `/uploads/([^"'\s)>]+)`，已兼容相对路径，无需修改 |
| 前端 `uploadFile` 回调（Editor.tsx L537–539） | 使用 `data.url` 作为 src，相对路径需要前端在渲染时补全 host:port（arch-frontend 负责） |
| 邮件/外链分享 | 不存在，无影响 |
| 单元测试 | `TestUpload_URLFormat` 断言需同步更新 |
