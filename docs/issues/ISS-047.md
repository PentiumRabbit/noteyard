## 现象

编辑器内一级标题（`#`）渲染字体比二级标题（`##`）更小。

## 根因

`Editor.css` 中存在历史遗留 override 规则（L316-320）：

```css
.editor-wrap .bn-block-outer:not([data-prev-type]) > .bn-block > .bn-block-content[data-content-type="heading"] {
  font-size: inherit;
  font-weight: 700;
}
```

`not([data-prev-type])` 匹配文档第一个块（通常是 h1），将其 `font-size` 强制为 `inherit`（约 16px）。
h2 因前面有 h1 块，带有 `[data-prev-type="heading"]`，不被匹配，保留 `1.5em`（约 24px）。
结果：h1 ≈ 16px < h2 ≈ 24px。

该规则已被后续 L322-341 的 `!important` 规则覆盖，属于无效遗留代码。

## 修复

删除该冗余 override 规则。h1/h2/h3 的正确 em 值由 L322-341 的 `!important` 规则保证。
