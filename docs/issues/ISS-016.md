# ISS-016 — 数据库单选/多选交互体验不符合预期

| 字段 | 内容 |
|------|------|
| ID | ISS-016 |
| 发现时间 | 2026-05-03 |
| 发现来源 | 用户反馈 |
| 状态 | 已修复 |
| 优先级 | P2 |

## 现象

点击 select/multi-select 单元格后下拉面板弹出，但交互行为不符合预期：
- 选项无法直接点击切换选中/取消
- 多选时每次选完选项就关闭了面板，无法连续选多个
- 下拉内没有"添加新选项"的快捷入口，需绕行到列头菜单

## 预期行为（对标 Notion）

**单选（select）：**
- 点击单元格 → 弹出选项列表
- 点击一个选项 → 选中并关闭面板
- 点击已选中的选项 → 取消选中，关闭面板
- 面板内有搜索框（可选）和"添加新选项"入口

**多选（multi-select）：**
- 点击单元格 → 弹出选项列表
- 点击选项 → 切换选中/取消，**面板保持打开**
- 已选中的选项显示勾选状态
- 点击面板外区域或按 Esc → 关闭
- 面板内有"添加新选项"入口
