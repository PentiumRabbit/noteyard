# ISS-018 — sidecar 端口固定为 8080 导致启动冲突

## 现象

noteyard 启动时若上一次的 noteyard-server 进程残留，新实例因 8080 端口被占用导致后端立即崩溃，前端无法加载数据。

## 根因

Go sidecar 端口硬编码为 8080，无动态分配机制。

## 用户需求

改为动态端口：Tauri 层选空闲端口 → 传给 Go sidecar → 前端从 Tauri 获取端口构建 API URL。
