# ISS-027 — 数据库视图公式弹窗超出视口，「编辑公式」功能表现消失

| 字段 | 内容 |
|------|------|
| ID | ISS-027 |
| 状态 | 🔴 待修复 |
| 优先级 | P1 |
| 发现日期 | 2026-05-04 |
| 发现人 | 用户 |

## 现象

数据库表格视图中，右键点击 formula 类型列的列头，菜单里出现「ƒ 编辑公式」按钮，点击后无任何反应（弹窗不可见），表现为公式编辑功能消失。

## 复现路径

1. 打开任意数据库视图
2. 确保视图有 formula 类型列，且表格行数较多（列头位于视口中下部）
3. 点击 formula 列列头，打开列菜单
4. 点击「ƒ 编辑公式」
5. 公式编辑弹窗不出现（实际渲染在视口下方，不可见）

视口上半部分的列头则可以正常打开公式弹窗。

## 根因

ISS-023（commit 0b23cc9）修复了所有弹窗的锚点定位，将硬编码的 `rect.bottom + offset` 统一改为 `getPopoverY(rect)`，使弹窗能根据视口位置自动选择向上或向下展开。

但该 commit **遗漏了 `openFormulaPopover` 函数**，该函数仍使用硬编码：

```ts
y: rect.bottom + 4
```

当列头菜单（`.col-menu`）位于视口下半部时，`rect.bottom + 4` 超出 `window.innerHeight`，公式弹窗渲染在屏幕可视区之外，用户无法看到。

受影响范围：仅 `openFormulaPopover`；其他弹窗（rollup、select options 等）已在 ISS-023 中修复。

## 修复方案

将 `openFormulaPopover` 中的 `y: rect.bottom + 4` 替换为 `y: getPopoverY(rect)`。

涉及文件：`web/src/components/database/DatabaseView.tsx` `openFormulaPopover` 函数。
