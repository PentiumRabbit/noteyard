# ISS-009: 应用图标只显示白色圆角方块，无橙色 N 字

## 状态
已修复

## 优先级
P1

## 现象
macOS Dock 及应用窗口中，应用图标仅显示白色圆角方块，橙色斜体 N 字未出现。

## 复现步骤
1. `make dev` 启动客户端
2. 观察 Dock 中 noteyard 图标

## 预期
白色圆角方块背景 + 橙色斜体 N 字

## 实际
纯白色圆角方块，无任何字样

## 已知信息
- `src-tauri/icons/icon.icns` 的 `hasAlpha: yes`，文件本身正确
- `src-tauri/icons/icon.png` ColorType=6（RGBA），文件本身正确
- binary 已在图标生成之后重新编译（时间戳确认）
- 怀疑方向：gen_icon7.py 生成的 N 字笔划坐标/颜色在渲染后不可见，或 tauri icon 工具转换时丢失了内容

## 报告人
总负责人

## 根因分析（总架构师）

`gen_icon7.py` 中 `set_px` 函数的像素合成逻辑使用了 Porter-Duff **DST-OVER**（目标置顶）而非 **SRC-OVER**（来源置顶）：

```python
# 错误（DST-OVER）：
new_a = a0/255 + a * (1 - a0/255)
r = (r0 * (a0/255) + r1 * a * (1 - a0/255)) / new_a
```

当背景（白色圆角方块）已以 `alpha=255` 完全不透明绘制后，`(1 - a0/255) = 0`，导致任何后续绘制（橙色 N 字）的权重为 0，橙色像素完全被白色背景压制，N 字不可见。

**修复**：改为 SRC-OVER，来源（橙色）覆盖目标（白色背景）：

```python
# 正确（SRC-OVER）：
out_a = src_a + dst_a * (1.0 - src_a)
r = (r1 * src_a + r0 * dst_a * (1.0 - src_a)) / out_a
```

## 修复记录（工程师）

- 修复 `gen_icon7.py` 的 `set_px` 合成公式，由 DST-OVER 改为 SRC-OVER
- 使用修复后的脚本重新生成 `/tmp/icon-source.png`
- 运行 `tauri icon /tmp/icon-source.png` 重新生成全部 50 个图标变体
