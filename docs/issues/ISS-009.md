# ISS-009: 应用图标只显示白色圆角方块，无橙色 N 字

## 状态
开放

## 优先级
P1

## 现象
macOS Dock 及应用窗口中，应用图标仅显示白色圆角方块，橙色斜体 N 字未出现。

## 复现步骤
1. `make dev` 启动客户端
2. 观察 Dock 中 noteyard 图标

## 预期
白色圆角方块背景 + 橙色斜体 N 字

## 实际
纯白色圆角方块，无任何字样

## 已知信息
- `src-tauri/icons/icon.icns` 的 `hasAlpha: yes`，文件本身正确
- `src-tauri/icons/icon.png` ColorType=6（RGBA），文件本身正确
- binary 已在图标生成之后重新编译（时间戳确认）
- 怀疑方向：gen_icon7.py 生成的 N 字笔划坐标/颜色在渲染后不可见，或 tauri icon 工具转换时丢失了内容
