# ISS-007 列类型选择器改为自定义下拉，支持图标和描述

| 字段 | 内容 |
|------|------|
| ISS ID | ISS-007 |
| 状态 | 待修复 |
| 日期 | 2026-05-02 |
| 优先级 | P2 |
| 来源 | 用户反馈 |

## 现象

新增列弹窗中的列类型选择使用原生 `<select><option>`，导致：
1. Lucide 图标无法在 `<option>` 内渲染，图标丢失
2. 样式粗糙，与产品期望的「图标 + 名称 + 描述」卡片列表风格不符

## 期望效果

参考 Notion 斜杠菜单风格：自定义下拉面板，每一项包含：
- 左侧图标区（Lucide 组件，灰色背景圆角）
- 右侧文字区：类型名称（粗体）+ 描述文字（次级色）

## 修复方案

将列类型 `<select>` 替换为自定义 div 下拉面板，复用 `ColIcon` 组件渲染图标，
每种列类型配一条中文描述，样式对齐截图风格。
