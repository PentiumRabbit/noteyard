# ISS-008 数据库块宽度与页面内容不对齐，ISS-006 修复引入回归

## 现象

1. 数据库块宽度超出页面正文列宽，表格横线延伸到页面边缘外，与上下段落文字不对齐
2. 数据库块左侧有 BlockNote 块选择蓝边指示器，视觉上形成蓝色左边框
3. 上方其他内容块（页面封面说明文字）左边被截断，疑似受同一 CSS 改动波及

## 根因

ISS-006 在 `.db-wrap` 上使用了 `margin: 4px -96px 16px` + `width: calc(100% + 192px)`，
意图突破编辑器内容列宽限制，但实际撑得过宽，破坏了与页面其他内容块的对齐关系，
同时 `Editor.css` 中 `[data-content-type="database"]` 的 `overflow: visible` 可能导致内容溢出影响相邻块。

## 修复目标

1. 数据库块左右边缘与页面正文内容对齐（与段落文字同宽）
2. 看板/日历等视图在块内横向滚动，不突破块边界
3. 消除 BlockNote 块选择蓝边（`contentEditable={false}` 块的聚焦样式）
4. 不影响其他内容块布局
