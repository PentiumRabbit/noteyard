## 现象

数据库视图中多个弹窗（列头菜单、添加列、选项配置等）锚点位置偏移，弹窗出现位置与触发元素不对齐。

## 根因

`getPopoverY` 依赖写死的估算高度（如 200、420）判断弹窗应向上还是向下展开。当实际高度与估算值偏差较大时（尤其弹窗内容多时），方向判断出错，导致位置偏移。

ISS-020 的 rAF 二次定位修法在首次点击时 `ref.current` 为 null，反而引入闪烁而未能修复问题。

## 修复方案

CSS 层给所有弹窗加 `max-height: calc(100vh - 24px); overflow-y: auto`，确保弹窗高度永远不超过视口。`getPopoverY` 改为使用保守的固定值（视口高度的一半）作为估算，只负责选方向，不依赖精确高度。同时移除 rAF 二次定位逻辑。
