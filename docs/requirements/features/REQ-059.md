## 背景

noteyard 数据库视图已具备基础的表格、看板、画廊、列表、日历、时间轴等视图，以及 14 种字段类型，REQ-057/058 完成了图标统一和 CSS 变量规范化。

然而与 Notion 相比，以下关键交互和功能仍存在明显差距：

1. **表格视图交互缺失**：列头编辑弹窗（字段编辑/重命名）、筛选/排序/分组面板交互停留在原始 `<select>` 下拉水平；无"新建筛选条件"按钮式 UI、排序无多条件支持、分组面板无选项列表。
2. **行详情弹窗**：当前为简单的字段 input 列表，点击行展开后无法在顶部写 Block 内容（Notion 的行详情可以当一个迷你页面用，有标题区域 + 内容 block 编辑器）。
3. **Select 选项编辑**：选项编辑弹窗功能已有，但 UX 不对齐 Notion——缺少拖拽排序、内联重命名、Notion 风格的颜色选择气泡。
4. **关联选择器**：已有基础 Picker，但缺少"新建并关联"按钮、搜索结果为空时的引导、关联行预览卡片。
5. **字段类型缺失**：phone（电话）、people（人员/负责人）、status（状态，类似 select 但带内置颜色预设和完成/未完成语义）三个高频字段类型尚未实现。
6. **其余视图 UI 细节**：看板列头颜色、画廊卡片封面、日历当日高亮、时间轴颜色条——与 Notion 视觉感差距明显，但功能上不缺失。

## 用户故事

**作为 noteyard 用户：**
1. 我希望点击列头后能在弹窗内方便地重命名、切换类型，并通过直观的 UI 编辑 Select 选项（包括内联重命名和拖拽排序）。
2. 我希望筛选/排序/分组面板有清晰的"添加条件"入口，配置后能直观看到已激活的条件数。
3. 我希望点击行展开时，能在行详情弹窗顶部写文字、标题等 block 内容，不只是字段值列表。
4. 我希望关联字段能在弹窗内搜索并快速新建关联行，而不只是从现有行中选。
5. 我希望能用 phone / people / status 三种字段类型记录电话、负责人和任务状态。
6. 我希望看板/画廊/日历/时间线/列表在视觉上更接近 Notion 的精致风格。

## 数据模型 / 实现方案

### 新增字段类型

在 `web/src/types/index.ts` 的 `DBColumn["type"]` union 中追加：

```ts
| "phone" | "people" | "status"
```

后端（`internal/database/` Go 层）同步追加这三种类型的枚举值与默认值处理。

### phone 字段

- 存储：纯文本字符串（同 text）
- 渲染：`<a href="tel:值">值</a>` 芯片，点击可拨号
- 编辑：`<input type="tel">`
- 图标：`Phone`（Lucide）

### people 字段

- 存储：逗号分隔字符串（同 multi-select，但无预设选项），v1 不做真实用户系统关联
- 渲染：每个姓名显示为灰色 chip
- 编辑：自由文本输入 + 逗号分隔解析
- 图标：`User`（Lucide）

### status 字段

- 存储：同 select，JSON 选项列表，默认初始化三档：
  ```json
  [
    {"value":"未开始","colorIdx":5},
    {"value":"进行中","colorIdx":1},
    {"value":"已完成","colorIdx":2}
  ]
  ```
- 渲染：带颜色点 + 标签，视觉上比 select 更紧凑
- 编辑：点击单元格出现自定义下拉（与 select 共用逻辑，但增加颜色点指示）
- 图标：`Circle`（Lucide，空心圆表示状态）

### 行详情弹窗内容编辑

- 在 `DBRow` 后端新增 `content` 字段（TEXT，存 BlockNote JSON）
- 前端 `row-modal` 顶部添加 BlockNote editor，绑定 `row.content`
- 保存时额外调用 `api.databases.updateRowContent(databaseId, rowId, contentJson)`
- BlockNote editor 使用只读配置子集（不含斜杠菜单的 database block）

### 筛选面板重构

从单个 `FilterState` 升级为 `FilterState[]`：

```ts
interface FilterState { id: string; colId: string; op: string; val: string }
```

- 面板显示条件列表，每行：列选择器 + 操作符 + 值输入 + × 按钮
- 底部"+ 添加筛选条件"按钮
- 后端 API 支持多个 filter 参数（AND 关系），或前端在加载后客户端过滤（v1 可先用前端过滤简化实现）
- 工具栏按钮 badge 显示已激活条件数

### 排序面板重构

从单个 `SortState` 升级为 `SortState[]`（v1 UI 支持多条，后端 v1 只传第一条）：

```ts
interface SortState { id: string; colId: string; order: "asc" | "desc" }
```

### Select 选项弹窗 UX 对齐

- 添加 `@dnd-kit/core` 拖拽排序（已安装 dnd-kit，KanbanView 已用）
- 每个选项行：颜色点 + 内联 input（不是 `<span>`）+ × 删除
- 颜色选择改为 Notion 风格的小色点气泡（已有 TAG_COLORS，只改呈现）

### 关联选择器增强

- 搜索无结果时显示"新建并关联「搜索词」"按钮
- 点击后：`api.databases.addRow(targetDbId)` + 写入 title 字段 + `toggleId(newRow.id)`
