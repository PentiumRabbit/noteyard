## 用户故事

作为 noteyard 用户，我希望编辑器支持 Callout 和 Toggle 折叠块，可以通过 Cmd+K 快速搜索页面，支持删除页面到回收站并可恢复，以及在数据库中复制行，使日常笔记和数据管理更高效。

**UI 风格要求（强制）**：所有 UI 细节必须与 Notion 保持一致，包括颜色、间距、图标、交互动效，不得自行发明样式。

---

## 功能范围

### 1. Callout 块（标注块）

通过斜杠菜单插入，包含左侧 emoji 图标区 + 右侧文本内容区。支持点击 emoji 更换图标，样式与 Notion Callout 一致（圆角背景色容器）。

### 2. Toggle 块（折叠块）

通过斜杠菜单插入，点击箭头展开/折叠子内容。折叠时子块完全隐藏，展开时正常渲染。支持嵌套其他块类型作为子内容。

### 3. 全文搜索（Cmd+K）

按下 Cmd+K 弹出搜索框，实时搜索所有页面的标题和内容，结果列表显示页面标题 + 内容摘要，点击跳转到对应页面。支持键盘 ↑↓ 导航和 Enter 确认。

### 4. 页面回收站

删除页面时移入回收站而非直接销毁。侧边栏提供「回收站」入口，列出已删除页面，支持恢复或永久删除。回收站页面不出现在正常页面列表中。

### 5. 数据库行复制

在数据库行的操作菜单中新增「复制行」按钮，复制当前行所有单元格数据为新行，插入到原行下方。

## 验收标准

- [ ] Callout 块可通过斜杠菜单插入，默认图标 💡，支持点击更换 emoji
- [ ] Toggle 块可通过斜杠菜单插入，点击箭头展开/折叠子内容，状态持久化
