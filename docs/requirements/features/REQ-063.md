## 背景

noteyard 目前没有全局搜索功能，用户只能通过侧边栏手动浏览页面树来找到目标页面。当页面数量增多后，查找效率极低。

目标：实现 `⌘K`（macOS）/ `Ctrl+K`（Windows/Linux）全局搜索，支持按页面标题和块内容搜索，搜索结果即时显示，点击结果跳转到对应页面。

---

## 功能范围

### F1 — 搜索入口

**触发方式：**
- 键盘快捷键：`⌘K`（macOS）/ `Ctrl+K`（Windows/Linux）
- 侧边栏顶部搜索按钮（如已有图标，改为打开搜索弹窗）

**行为要求：**
- 任意状态下（编辑器打开、空态、设置页）均可触发搜索
- 触发后弹出搜索模态框，输入框自动聚焦
- 按 `Esc` 或点击遮罩关闭搜索模态框

---

### F2 — 搜索模态框 UI

**布局：**

```
┌─────────────────────────────────────┐
│  🔍  搜索页面和内容...               │
├─────────────────────────────────────┤
│  最近访问（空搜索词时显示）           │
│  ┌─────────────────────────────────┐│
│  │ 📄 页面标题 A                   ││
│  │ 📄 页面标题 B                   ││
│  └─────────────────────────────────┘│
├─────────────────────────────────────┤
│  搜索结果（有搜索词时显示）           │
│  ┌─────────────────────────────────┐│
│  │ 📄 [标题匹配] 页面标题           ││
│  │    /路径/到/页面                 ││
│  │ 📄 [内容匹配] 页面标题           ││
│  │    ...匹配的内容片段...          ││
│  └─────────────────────────────────┘│
└─────────────────────────────────────┘
```

**UI 细节：**
- 模态框宽度 560px，最大高度 480px，超出滚动
- 输入框无边框，全宽，字号 16px
- 结果列表每项高度 56px（有内容片段）或 40px（纯标题匹配）
- 键盘 ↑↓ 可选中结果项，Enter 跳转
- 鼠标悬停高亮结果项
- 搜索词匹配部分加粗高亮
- 无结果时显示「未找到与「xxx」匹配的页面」

---

### F3 — 搜索后端 API

**接口：`GET /api/search?q={query}&limit={limit}`**

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| q | string | 是 | — | 搜索关键词，最短 1 字符 |
| limit | int | 否 | 20 | 返回结果上限，最大 50 |

**响应：**
```json
{
  "results": [
    {
      "page_id": "uuid",
      "page_title": "页面标题",
      "page_icon": "📄",
      "page_path": ["父页面1", "父页面2"],
      "match_type": "title",
      "snippet": null
    },
    {
      "page_id": "uuid",
      "page_title": "另一页面",
      "page_icon": null,
      "page_path": [],
      "match_type": "content",
      "snippet": "...匹配的内容片段（最多 80 字符）..."
    }
  ]
}
```

**搜索逻辑：**
- 标题匹配：`pages.title LIKE '%{query}%'`（不区分大小写）
- 内容匹配：`blocks.content LIKE '%{query}%'`，取匹配块所在页面
- 排序：标题匹配优先于内容匹配；同类型内按 `pages.updated_at DESC`
- 去重：同一页面如既有标题匹配又有内容匹配，只返回一条（标题匹配优先）
- `page_path`：返回从根到当前页面的父页面标题列表（不含当前页面自身）

---

### F4 — 最近访问

当搜索输入框为空时，显示最近访问的页面列表（最多 8 条）。

**数据来源：** 前端本地状态 `recentPages`，每次打开页面时记录 `page_id`，存入 `localStorage`，FIFO 队列，最多保留 8 条，去重（同一页面不重复）。

**显示内容：** 页面图标 + 页面标题，无内容片段，无路径显示。

---

### F5 — 跳转行为

点击搜索结果或键盘 Enter 确认后：
- 关闭搜索模态框
- 将对应 `page_id` 设为当前选中页面（`selectedPageId`）
- 侧边栏对应页面条目高亮
- 如目标页面在树中被折叠，展开其所有祖先节点

## 场景矩阵

| # | 场景 | 前提 | 操作 | 预期结果 |
|---|------|------|------|---------|
| 1 | 打开搜索框 | 任意状态 | 按 ⌘K / Ctrl+K | 搜索模态框弹出，输入框聚焦 |
| 2 | 关闭搜索框 | 搜索框已打开 | 按 Esc 或点击遮罩 | 搜索框关闭，回到原界面 |
| 3 | 标题搜索 | 有多个页面 | 输入页面标题的一部分 | 结果列表显示匹配页面，标题含匹配高亮 |
| 4 | 内容搜索 | 某页面块内容含搜索词 | 输入内容关键词 | 显示该页面，snippet 含匹配内容片段 |
| 5 | 无结果 | 已有页面 | 输入不存在的关键词 | 显示「未找到...」提示 |
| 6 | 空搜索词 | 有访问历史 | 打开搜索框，不输入 | 显示最近访问页面列表 |
| 7 | 键盘导航 | 搜索结果已显示 | ↓ 选中第一条，Enter | 跳转到该页面，搜索框关闭 |
| 8 | 跳转折叠页面 | 目标页面祖先节点折叠 | 点击搜索结果 | 侧边栏展开路径，页面高亮 |
| 9 | 搜索防抖 | 搜索框已打开 | 快速连续输入 | API 请求仅在停止输入 200ms 后发出 |
| 10 | 中文搜索 | 有中文页面/内容 | 输入中文关键词 | 正确匹配，结果无乱码 |

## 不在范围

- 搜索结果内容高亮定位（跳转到页面后不自动滚动到匹配的块位置）
- 模糊搜索 / 拼音搜索（仅 LIKE 子串匹配）
- 搜索历史持久化（仅最近访问，不记录搜索词）
- 文件附件内容搜索（仅文本块 content 字段）
- 搜索结果分页
