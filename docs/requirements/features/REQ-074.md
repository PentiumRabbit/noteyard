## 背景

当前未选中页面时，主区域仅显示一行提示文字「从左侧选择页面，或点击 + 新建」，对新用户无引导价值。

目标：空状态时始终展示一份简短的快速入门说明，让用户在不打开任何页面的情况下快速了解核心操作；同时提供一键导入按钮，将说明内容导入为可编辑的普通页面。

---

## 范围

### 空状态区域（`App.tsx` `.empty-state`）

- 移除现有"从左侧选择页面，或点击 + 新建"提示文字
- 替换为快速入门说明卡片，始终展示（无一次性 flag，不可关闭）
- 卡片底部提供「导入为页面」按钮，点击后调用现有导入逻辑，将说明 JSON 导入为可编辑页面，并自动跳转到该页面

### 说明内容

- 格式：noteyard JSON block 格式（与 REQ-070 `welcome.json` 相同的 seed 方言）
- 预置在前端代码中（`web/src/data/quickstart.json`），不依赖 API
- 内容：独立的快速入门说明，比欢迎页更简短，覆盖以下要点：

| 章节 | 块类型 | 说明 |
|------|--------|------|
| 标题 | heading(H1) | 「快速开始」 |
| 创建页面 | heading(H2) + bulletList | 侧边栏 + 按钮新建、拖拽排序、嵌套子页面 |
| 块编辑器 | heading(H2) + bulletList | 斜杠菜单、拖拽移动块、格式化工具栏 |
| 数据库 | heading(H2) + bulletList | 插入数据库块、添加字段与行 |
| 常用快捷键 | heading(H2) + bulletList | ⌘K 搜索 / / 斜杠菜单 / ⌘Z 撤销 |

- 总块数控制在 20 个以内，保持简洁

### 渲染方式

- 空状态卡片内用轻量 HTML 渲染（不复用 Editor 组件，避免引入编辑状态），仅展示纯文本结构
- 卡片有固定最大宽度（≤ 600px），居中显示，有适当内边距和分区标题样式

### 导入行为

- 调用现有导入接口（与"导入 JSON 文件"功能相同的后端路径）
- 导入成功后自动 `handleSelect` 跳转到新页面
- 导入失败时展示错误提示，不跳转

---

## 不在范围

- 说明内容的可配置化 / 国际化
- 空状态卡片的可关闭 / 一次性展示逻辑
- 与 REQ-070 欢迎页内容复用（两份内容独立维护）
- 图片、数据库块嵌入到说明卡片中

---

## 验收标准

- [ ] 未选中页面时，主区域展示快速入门说明卡片，不再显示原提示文字
- [ ] 说明卡片内容覆盖上述 5 个章节
- [ ] 点击「导入为页面」后，说明内容以 JSON block 格式导入数据库，自动跳转到该页面
- [ ] 导入后页面可正常编辑（块可增删改）
- [ ] 重新回到空状态（未选中页面），说明卡片依然展示（导入不影响空状态展示）
- [ ] 说明卡片最大宽度 ≤ 600px，居中，视觉整洁
