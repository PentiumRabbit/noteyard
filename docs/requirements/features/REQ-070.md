## 背景

当前欢迎页内容（45 个块）硬编码在 `server/internal/db/seed.go` 中，以 Go 字符串字面量形式维护，存在以下问题：

1. **内容与代码耦合**：修改欢迎页文字需要改 Go 代码并重新编译
2. **可读性极差**：45 个块的 JSON 散落在代码中，难以理解整体结构
3. **扩展性受限**：未来欢迎页如需包含数据库块、并排布局等复杂块类型，硬编码维护成本急剧上升
4. **迁移机制不兼容**：新版迁移系统（`schema_migrations` 表）与旧版（`migrations` 时间戳表）并存，欢迎页 seed（v2/v3）在已有旧数据库上不生效

目标：将 seed 内容提取为独立 JSON 文件，服务端启动时解析并写入数据库，内容修改无需改代码。

## Seed 文件格式规范

### 文件路径

```
server/internal/db/seeds/
  welcome.json        # 欢迎页 seed
  (future).json       # 未来可扩展其他 seed
```

### 格式：BlockNote Seed 方言（JSON）

Seed 文件是 BlockNote 块结构的简化方言。服务端读取后执行一次转换（补全 UUID、timestamps、order_index）再写入 DB。

#### 顶层结构

```json
{
  "version": 1,
  "page": {
    "id": "00000000-0000-0000-0000-000000000001",
    "title": "欢迎使用 noteyard",
    "icon": "👋",
    "order_index": 0
  },
  "blocks": [ ...块数组... ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `version` | int | Seed 格式版本，当前为 1 |
| `page.id` | string | 固定 UUID，用于幂等检查 |
| `page.title` | string | 页面标题 |
| `page.icon` | string | Emoji 图标 |
| `page.order_index` | float | 侧边栏排序，0 = 最顶 |
| `blocks` | array | 块定义数组，见下方块格式 |

#### 块格式

每个块包含以下字段：

```json
{
  "id": "00000000-0000-0000-0001-000000000001",
  "type": "heading",
  "props": { "level": 1 },
  "content": "欢迎使用 noteyard 👋",
  "children": []
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 固定 UUID，用于幂等 re-seed |
| `type` | string | 是 | BlockNote 块类型，见下方支持列表 |
| `props` | object | 否 | 块属性，缺省时使用各类型默认值 |
| `content` | string \| array | 否 | 字符串时自动展开为 inline content 数组；数组时直接使用（原生 BlockNote inline content 格式） |
| `children` | array | 否 | 子块数组，用于 columnList 等嵌套结构 |

#### 支持的块类型

| type | props 示例 | content 说明 |
|------|-----------|-------------|
| `heading` | `{"level": 1}` | 标题文字 |
| `paragraph` | `{}` | 段落文字 |
| `bulletListItem` | `{}` | 无序列表项 |
| `numberedListItem` | `{}` | 有序列表项 |
| `quote` | `{}` | 引用块文字 |
| `callout` | `{"icon": "💡"}` | 标注块文字 |
| `horizontalRule` | `{}` | 无 content |
| `toggleListItem` | `{}` | 折叠块标题，子内容放 children |
| `columnList` | `{}` | 并排布局容器，子块放 children |
| `column` | `{}` | 单列容器，必须是 columnList 的直接子块 |

**数据库块（database）暂不在 seed 格式支持范围内**，欢迎页不内嵌数据库。

#### content 字符串自动展开规则

当 `content` 为字符串时，服务端转换器将其展开为：

```json
[{"type": "text", "text": "<content值>", "styles": {}}]
```

当 `content` 为数组时，直接使用，允许包含多段富文本（加粗、斜体、code 等）：

```json
[
  {"type": "text", "text": "输入 ", "styles": {}},
  {"type": "text", "text": "/", "styles": {"bold": true}},
  {"type": "text", "text": " 打开块菜单", "styles": {}}
]
```

#### columnList / column 嵌套示例

```json
{
  "id": "00000000-0000-0000-0001-000000000050",
  "type": "columnList",
  "children": [
    {
      "id": "00000000-0000-0000-0001-000000000051",
      "type": "column",
      "children": [
        {
          "id": "00000000-0000-0000-0001-000000000052",
          "type": "paragraph",
          "content": "左列内容"
        }
      ]
    },
    {
      "id": "00000000-0000-0000-0001-000000000053",
      "type": "column",
      "children": [
        {
          "id": "00000000-0000-0000-0001-000000000054",
          "type": "paragraph",
          "content": "右列内容"
        }
      ]
    }
  ]
}
```

## 服务端实现要求

### 转换器（seed → DB rows）

新建 `server/internal/db/seeds/loader.go`，提供：

```go
// LoadSeed 读取 JSON 文件，返回可写入 DB 的 page + blocks
func LoadSeed(path string) (*SeedPage, []SeedBlock, error)

// ApplySeed 幂等写入：若 page.id 已存在则跳过，不存在则插入
func ApplySeed(tx *sql.Tx, page *SeedPage, blocks []SeedBlock) error
```

转换规则：
- `content` 为字符串 → 自动展开为 `[{"type":"text","text":"...","styles":{}}]`
- `content` 为数组 → 直接序列化为 JSON 字符串写入 `blocks.content`
- `props` 缺省 → 各块类型有合理默认值（heading 默认 level=1，callout 默认 icon=💡 等）
- `order_index` 按块在数组中的位置自动生成（1.0, 2.0, 3.0, ...），嵌套子块同理
- `parent_block_id`：顶层块为 NULL，column 内的块指向对应 column 块的 id，column 块指向 columnList 块的 id

### 迁移注册

在 `server/internal/db/seed.go` 中：
- 保留现有 `WelcomeSeedMigration`（v2）和 `cleanWelcomeBlocks`（v3）的迁移注册，**不删除**（保证旧数据库平滑升级）
- 新增 migration v4：调用 `ApplySeed` 读取 `seeds/welcome.json`，若欢迎页已存在（固定 ID 检查）则跳过，不存在则插入
- 同时修复迁移兼容性：`RunMigrations` 启动时若发现旧 `migrations` 表存在，将已有版本号对应记录同步写入 `schema_migrations`，确保 v2/v3/v4 不重复执行

### 旧硬编码处理

- `seed.go` 中的 `WelcomeSeedMigration`（v2）和 `cleanWelcomeBlocks`（v3）**保留函数体不删除**，确保旧数据库升级路径完整
- 新版欢迎页内容仅通过 `seeds/welcome.json` 维护，`seed.go` 不再硬编码块内容

## 欢迎页内容要求

`seeds/welcome.json` 重新编写欢迎页，覆盖以下章节：

| 章节 | 块类型 | 说明 |
|------|--------|------|
| 标题 + 简介 callout | heading(H1) + callout | 应用介绍 |
| 页面与导航 | heading(H2) + numberedList | 创建/嵌套/拖拽/重命名/删除 |
| 块编辑器 | heading(H2) + bulletList + callout | 斜杠菜单、拖拽、格式化 |
| 数据库 | heading(H2) + numberedList + callout | 插入/字段/行/视图切换 |
| 页面装饰 | heading(H2) + bulletList | 封面、图标 |
| 并排布局 | heading(H2) + numberedList + callout | 拖拽分栏操作说明 |
| 常用快捷键 | heading(H2) + bulletList | ⌘K / / / ⌘Z 等 |
| 尾注 | horizontalRule + quote | 结语 |

内容与现有 `seed.go` 中的文字保持一致，格式迁移到新 JSON 方言，无需改文案。

## 不在范围

- 数据库块的 seed 格式支持（未来可扩展，本期不做）
- Markdown 导入转换器
- seed 文件的热重载（运行时更新，重启生效即可）
- 多语言 seed 支持
