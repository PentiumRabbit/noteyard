## 背景

当前 DatabaseView 及其子视图中的图标使用方式混乱，存在以下四类问题：

1. **列类型图标（COL_ICONS）**：混用 emoji（📅 🔗 ✉ 🕐 🕑 📎）、特殊 Unicode 字符（Aa # ☑ ≡ ƒ Σ）和纯文字符号，在不同操作系统、字体下渲染效果差异大，无法统一尺寸和颜色。

2. **视图切换按钮**：仅有文字标签（表格 / 看板 / 库 / 列表 / 日历 / 时间轴），缺少配套图标，视觉层次弱。

3. **工具栏按钮**：筛选 / 排序 / 隐藏字段 / 分组均为纯文字按钮，无图标前缀，识别成本高。

4. **操作按钮**：新增行（+）、新增列（+）、行展开（↗）、行复制（⊕）、行删除（⊖）等使用 ASCII / Unicode 符号，与整体视觉风格割裂。

引入 **lucide-react**（已在 Lucide 生态广泛使用的 MIT 线条 SVG 图标库），统一替换上述四类图标，实现一致的 16px/14px 线条风格。

**不在本期范围**：编辑器侧（BlockNote 工具栏、斜杠菜单等）的图标不作任何修改。

---

## 用户故事

作为 noteyard 用户，我希望数据库视图的所有图标（列类型、视图切换、工具栏、操作按钮）视觉风格统一、清晰易识别，在不同操作系统下均能正常渲染，不出现 emoji 或框框乱码。

## 数据模型 / 实现方案

### 依赖安装

```bash
npm install lucide-react
```

lucide-react 提供 Tree-shakeable 的 React SVG 组件，每个图标为独立命名导出，构建工具（Vite）可自动 Tree-shake，仅打包实际使用的图标。

### COL_ICONS 映射（列类型 → Lucide 组件）

| 列类型 | Lucide 组件 | 语义说明 |
|--------|-------------|---------|
| text | `Type` | 文字 |
| number | `Hash` | 数字 |
| checkbox | `CheckSquare` | 复选框 |
| select | `ChevronDown` | 单选下拉 |
| multi-select | `Tags` | 多标签 |
| date | `Calendar` | 日期 |
| formula | `FunctionSquare` | 函数/公式 |
| url | `Link` | 链接 |
| email | `Mail` | 邮件 |
| created_time | `Clock` | 创建时间 |
| last_edited_time | `Clock3` | 最后编辑时间 |
| files | `Paperclip` | 附件 |
| relation | `ArrowUpRight` | 关联跳转 |
| rollup | `Sigma` | 汇总/求和 |

### 视图图标映射

| 视图 | Lucide 组件 |
|------|-------------|
| table（表格） | `Table` |
| kanban（看板） | `Columns` |
| gallery（库） | `LayoutGrid` |
| list（列表） | `List` |
| calendar（日历） | `CalendarDays` |
| timeline（时间轴） | `GanttChartSquare` |

### 工具栏图标映射

| 按钮 | Lucide 组件 |
|------|-------------|
| 筛选 | `Filter` |
| 排序 | `ArrowUpDown` |
| 隐藏字段 | `EyeOff` |
| 分组 | `Rows` |

### 操作图标映射

| 操作 | 当前符号 | Lucide 组件 |
|------|---------|-------------|
| 新增列 / 新增行 | `+` | `Plus` |
| 展开行 | `↗` | `ExternalLink` |
| 复制行 | `⊕` | `Copy` |
| 删除行 | `⊖` | `Trash2` |
| 列表视图行图标 | `📄` | `FileText` |

### 组件用法规范

```tsx
import { Hash, Type, Calendar } from "lucide-react";

// 列图标：size=14, 颜色继承父元素（使用 CSS 的 color 属性）
<Hash size={14} />

// 视图/工具栏图标：size=16
<Table size={16} />

// 行操作图标：size=14
<Trash2 size={14} />
```

所有图标使用 `currentColor`（Lucide 默认），通过 CSS 控制颜色：
- 默认列类型图标：`color: #9ca3af`（灰色）
- 工具栏激活态：`color: #374151`
- 筛选/排序已设置：`color: #2383e2`（强调蓝）

## 验收标准

- [ ] `lucide-react` 已添加到 `web/package.json` 的 `dependencies`，`npm install` 后构建无报错
- [ ] `COL_ICONS` 类型从 `Record<DBColumn["type"], string>` 改为 `Record<DBColumn["type"], React.ComponentType<{ size?: number }>>` 或等效泛型，不再使用字符串
- [ ] 14 种列类型均有对应 Lucide 图标，无遗漏；新增未知类型时 fallback 到 `HelpCircle`
- [ ] 6 种视图切换按钮各有图标前缀，文字标签保留
- [ ] 工具栏 4 个按钮（筛选 / 排序 / 隐藏字段 / 分组）各有图标前缀
- [ ] 新增行、新增列按钮使用 `<Plus>` 图标
- [ ] 行操作按钮（展开 / 复制 / 删除）使用对应 Lucide 图标
- [ ] 列表视图中行图标使用 `<FileText>`（替换 `📄`）
- [ ] 图标颜色通过 CSS `color` 属性控制，不硬编码 `stroke` 属性
- [ ] 激活/非激活状态视觉区分明确（颜色变化）
- [ ] 编辑器侧（BlockNote）代码无任何修改
- [ ] Vite 构建通过，bundle size 增量 < 30 KB（Tree-shake 后）
