## 背景

项目中存在两类视觉一致性问题：
1. 编辑器内的"按钮块"样式偏定制化（颜色色块按钮），与 Notion 的极简风格不符
2. 多处使用浏览器原生 `<select>` 下拉控件，视觉与整体 UI 主题割裂

## 需求

### 1. 按钮块样式对齐 Notion

Notion 的 Button 块特点：
- 按钮背景色极浅（几乎透明），带浅色边框，圆角 4px
- 文字颜色与强调色一致（或深色），字号 14px，font-weight 500
- hover 时背景色微微加深
- 不使用鲜艳的纯色填充（蓝/绿/红）
- 左侧可选 emoji/icon，通过点击弹出配置面板
- 配置面板：标签文案 + 颜色 + 动作 + URL（如适用）

具体样式调整：
- `.button-block-btn` 移除 `color-blue/green/red/gray` 分类色，改为统一的 Notion 风格：`background: var(--color-bg-surface)`, `border: 1px solid var(--color-border-medium)`, `color: var(--color-text-primary)`, hover 背景微加深
- 颜色选项改为「默认/蓝/绿/红/橙/紫」，每种颜色仅改变文字颜色（不改背景），对应 Notion 的 colored text 风格

### 2. 全局去除 Native `<select>` 控件

需替换的位置（全部改为自定义下拉组件 `CustomSelect`）：

| 文件 | 位置 | 用途 |
|------|------|------|
| `web/src/components/common/PanelSelect.tsx` | 整个组件 | 通用面板下拉 |
| `web/src/components/database/RollupConfigPopover.tsx` | line ~162, ~183, ~200 | rollup 配置三个下拉 |
| `web/src/components/database/CalendarView.tsx` | line ~49 | 日期列选择 |
| `web/src/components/database/TimelineView.tsx` | line ~100 | 日期列选择 |
| `web/src/components/database/RowModal.tsx` | line ~194 | 字段类型选择 |
| `web/src/components/database/DatabaseView.tsx` | line ~708, ~745 | 批量操作、看板分组 |

**`CustomSelect` 组件设计**：
- 触发器：`div` 或 `button`，显示当前选中值 + 右侧小箭头（▾）
- 样式：与 `PanelSelect` 现有样式一致（border, border-radius, padding, font-size）
- 下拉菜单：绝对定位浮层，每项 `div` hover 高亮，点击选中后关闭
- 支持 `value`, `onChange`, `options: {value, label}[]`, `className?` props
- 点击外部关闭（`useEffect` + `document` click listener）
- 放在 `web/src/components/common/CustomSelect.tsx`

**不需要替换的**：
- `<input type="text">`, `<input type="number">`, `<input type="checkbox">` 等文本/数字/复选框输入框，保持不变
- BlockNote 内部渲染的原生控件（如代码块语言选择）不属于项目代码，不处理
- `<input type="file">` 隐藏上传控件，保持不变（视觉上被自定义按钮覆盖）

## 验收标准

1. 编辑器内插入 Button 块，样式与 Notion 一致（浅背景、边框、hover 效果）
2. 全局所有自定义 UI 中的 `<select>` 均被替换为 `CustomSelect`，视觉风格统一
3. `CustomSelect` 点击外部可关闭，键盘（Escape）可关闭
4. 原有功能不受影响（database 视图、看板分组、rollup 配置等正常工作）
5. tsc --noEmit 零错误
