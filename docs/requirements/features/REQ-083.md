## 背景

按钮块（REQ-054）已支持基础的文案、文字颜色、打开链接动作。本次增强涵盖四项能力：

1. **背景色**：设置面板新增背景色选择器，对齐 Notion colored background 风格。
2. **修复打开链接**（ISS-043）：`open_url` 动作点击主按钮无响应，需修复点击处理逻辑。
3. **新建子页面**：新增动作类型，点击按钮在当前页面下创建子页面并跳转。
4. **编辑页面属性**：新增动作类型，点击按钮弹出当前页面的属性编辑面板（图标 / 封面 / 标题）。

---

## 功能需求

### FR-1 背景色选择器

在按钮块设置面板中新增「背景色」区域，位于现有「颜色」（文字色）区域之后。

**propSchema 新增字段**：
- `bgColor`：按钮背景色，类型 `ButtonBgColor`，默认 `"default"`

**可选值与对应颜色**（对齐 Notion colored background）：

| 值 | 显示名 | 背景色（近似） |
|----|--------|---------------|
| `default` | 默认 | `var(--color-bg-surface)` |
| `gray` | 灰色 | `#f1f1ef` |
| `brown` | 棕色 | `#f4eeee` |
| `orange` | 橙色 | `#fbecdd` |
| `yellow` | 黄色 | `#fef9c3` |
| `green` | 绿色 | `#e8f5e8` |
| `blue` | 蓝色 | `#e7f0fd` |
| `purple` | 紫色 | `#f3eef8` |
| `pink` | 粉色 | `#fbe8f3` |
| `red` | 红色 | `#fde8e8` |

深色主题下背景色应使用对应的暗色变体（CSS 变量或 `.dark` 选择器覆盖）。

**面板 UI**：与现有颜色选择器（`.color-swatch-row`）相同的方块点选式，标签为「背景色」。

**改动范围**：
- `web/src/components/editor/Editor.tsx`：`ButtonBlock` propSchema 新增 `bgColor`，渲染层读取并应用背景色，设置面板新增背景色选择器。
- `web/src/components/editor/Editor.css`：新增 `.button-block-btn.bg-*` 背景色变体样式。

### FR-2 修复「打开链接」点击无响应（ISS-043）

**问题**：见 `docs/issues/ISS-043.md`。

**预期行为**：
1. action = `open_url`、url 为合法 `http/https` 链接 → 点击主按钮在新标签页打开链接。
2. action = `open_url`、url 为空或非 `http/https` → 点击主按钮弹出提示「URL 不合法：必须以 http:// 或 https:// 开头」，不跳转。
3. action = `none` → 点击无副作用（现有行为保持）。

**修复方向**：参照 ISS-041/ISS-042 解法，将主按钮点击处理改为原生 `addEventListener("mousedown")` + `e.stopPropagation()`，绕过 ProseMirror atom 节点事件拦截。详见 `docs/issues/ISS-043.md §修复方向`。

**改动范围**：`web/src/components/editor/Editor.tsx`，`ButtonBlock` render 函数。

### FR-3 新建子页面动作

**新增 action 类型**：`"new_subpage"`

**行为**：点击主按钮时：
1. 调用 `api.pages.create({ parent_id: pageId, title: "Untitled", order_index: 9999 })`，在当前页面下创建子页面（`parent_id` 为 Editor 接收的 `pageId` prop）。
2. 在编辑器当前光标位置（或按钮块之后）插入一个 `subpage` 块，指向新建页面（参照斜杠菜单 `subpageItem.onItemClick` 逻辑）。
3. 调用 `onSelectPage(newPage.id)` 跳转到新建页面。

**设置面板**：动作选项新增「新建子页面」；选中后无额外配置项（无 URL 输入框）。

**改动范围**：
- `web/src/components/editor/Editor.tsx`：`ButtonBlock` propSchema `action` 枚举新增 `"new_subpage"`，`handleClick` 新增对应分支，设置面板动作下拉新增选项。

---

### FR-4 编辑页面属性动作

**新增 action 类型**：`"edit_page_props"`

**行为**：点击主按钮时，在编辑器内弹出当前页面的属性编辑面板，提供以下三项可编辑属性：

| 属性 | 编辑方式 | 保存方式 |
|------|---------|---------|
| 图标（icon） | Emoji 点选（复用 App.tsx 中现有 EMOJI_COMMON 列表与点选逻辑） | `api.pages.update(pageId, { icon })` |
| 封面（cover） | 「添加/更换默认封面」按钮 + 「删除封面」按钮（复用 App.tsx 中现有 handleAddCover / handleRemoveCover 逻辑） | `api.pages.update(pageId, { cover })` |
| 标题（title） | 单行文本输入框，失焦或回车保存 | `api.pages.update(pageId, { title })` |

面板以 `position: fixed` 定位（同设置面板方案，参见 ISS-042），打开坐标由主按钮位置 `getBoundingClientRect()` 计算，点击外部关闭。

**设置面板**：动作选项新增「编辑页面属性」；选中后无额外配置项。

**数据获取**：面板打开时通过 `api.pages.get(pageId)` 拉取最新页面数据，回填到面板输入框。

**改动范围**：
- `web/src/components/editor/Editor.tsx`：`ButtonBlock` propSchema `action` 枚举新增 `"edit_page_props"`，新增页面属性面板组件（内联或独立子组件均可），设置面板动作下拉新增选项。
- `web/src/components/editor/Editor.css`：新增页面属性面板样式。

## 场景矩阵

**场景矩阵**:（格式见 docs/engineering/templates/scenario-matrix-template.md）

| 维度 | 场景 | 预期行为 |
|------|------|---------|
| 输入有效性（FR-1） | 背景色选择「蓝色」 | 按钮块背景变为浅蓝色，刷新后持久 |
| 输入有效性（FR-1） | 背景色选择「默认」 | 按钮块恢复默认背景（`var(--color-bg-surface)`） |
| 输入有效性（FR-2） | action=open_url，url=`https://example.com` | 点击主按钮在新标签页打开链接 |
| 输入有效性（FR-2） | action=open_url，url 为空 | 点击主按钮弹出「URL 不合法」提示，不跳转 |
| 输入有效性（FR-2） | action=open_url，url=`javascript:alert(1)` | 点击主按钮弹出「URL 不合法」提示，不执行脚本 |
| 输入有效性（FR-3） | action=new_subpage，点击主按钮 | 在当前页面下创建子页面，编辑器插入 subpage 块，跳转到新页面 |
| 输入有效性（FR-4） | action=edit_page_props，点击主按钮 | 弹出页面属性面板，显示当前页面图标/封面/标题 |
| 输入有效性（FR-4） | 属性面板中修改标题后失焦 | 调用 api.pages.update 保存，页面标题实时更新 |
| 前置条件/状态（FR-3） | 当前页面 pageId 有效 | 子页面创建成功，`parent_id` 正确指向当前页面 |
| 前置条件/状态（FR-3） | api.pages.create 接口失败（网络错误） | 按钮恢复正常状态，控制台输出错误，不插入 subpage 块 |
| 前置条件/状态（FR-4） | api.pages.get 失败（网络错误） | 面板内容降级为空，不影响面板打开 |
| 数量/规模边界（FR-1） | 同时设置文字颜色为红色、背景色为蓝色 | 两种颜色独立生效，样式无互相覆盖 |
| 来源/优先级（FR-2/3/4） | 按钮设置多次切换 action 类型后保存 | 最终保存的 action 值生效，无旧 action 残留 |
| 幂等性（FR-3） | 连续点击「新建子页面」按钮两次 | 创建两个独立子页面，不去重；每次点击均触发创建（此为预期，非 bug） |

**不适用维度说明**：「来源/优先级」维度中的多来源冲突不适用，按钮块配置来源单一（设置面板写入 propSchema），无多来源竞争场景。
