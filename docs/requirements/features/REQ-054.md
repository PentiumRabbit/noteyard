## 背景

BlockNote 编辑器已支持多种自定义块（Callout、Toggle、FileAttach 等），均通过 `createReactBlockSpec` 注册并在斜杠菜单中暴露。按钮块是一个可配置动作的交互块，用户可在文档内放置一个按钮并绑定特定行为（如打开链接、触发复制页面等），对齐 Notion Button 块的核心功能。

现有技术基础：
- 所有自定义块统一在 `web/src/components/editor/Editor.tsx` 中以 `createReactBlockSpec` 定义
- 块 props 通过 BlockNote propSchema 描述，序列化为 JSON 存入 `blocks.props` 字段
- 斜杠菜单通过 `DatabaseSlashItem` 组件扩展

---

## 用户故事

作为 noteyard 用户，我希望在文档中插入一个按钮，并配置其文案、颜色和点击行为，使文档具备一定的可交互性。

## 数据模型

### 块类型

`Block.type` = `"button"`

### propSchema

```typescript
interface ButtonBlockProps {
  label: string;        // 按钮文案，默认 "点击"
  color: string;        // 按钮颜色，默认 "blue"，可选 "blue"|"green"|"red"|"gray"
  action: string;       // 动作类型，默认 "none"，可选 "none"|"open_url"
  url: string;          // action="open_url" 时使用，默认 ""
}
```

### 持久化方式

按钮块属于「props-as-content」类型，与 `fileAttach`、`bookmark` 一致：
- `blocks.type` = `"button"`
- `blocks.content` = `JSON.stringify(props)`（BlockNote props 对象）
- `blocks.props` = `"{}"`

`toBlockNote.ts` 中需将 `"button"` 加入 props-as-content 分支；`buildDtosRecursive` 同理。

## 验收标准

- [ ] 斜杠菜单输入 `/button` 可插入按钮块，默认文案「点击」、蓝色、无动作
- [ ] 按钮文案可在块内直接编辑，失焦后 BlockNote 自动序列化持久
- [ ] 设置面板可切换动作类型（无 / 打开链接）；选择「打开链接」后出现 URL 输入框
- [ ] 填写合法 URL 后点击按钮，`window.open(url, '_blank')` 执行；`javascript:` 协议被拦截
- [ ] 颜色选项至少 4 种（蓝/绿/红/灰），切换后样式即时生效，刷新后持久
- [ ] 导出 Markdown 时输出 `[label](url)` 或 `[label]`（无链接时）
- [ ] props JSON 损坏时降级为默认状态，不抛未捕获异常
