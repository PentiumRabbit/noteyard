## 用户故事

作为 noteyard 用户，我希望编辑器的每一处视觉细节和交互体验都与 Notion 保持一致，包括页面结构、侧边栏、编辑器块类型、格式化工具栏和数据库表格。

---

## 功能范围

### A. 页面结构（Page Layout）

#### A-01 页面顶部区域
- **Cover 封面**：页面顶部可添加全宽封面图（图片），高度 160px
  - 鼠标悬停时显示"更换封面 / 删除封面"操作浮层
  - 目前不实现（后端无此字段，本期跳过）
- **Icon 图标**：标题上方可设置 emoji 图标，尺寸 60px
  - 点击图标弹出 emoji 选择器（简单版：输入框过滤 + 常用列表）
  - 图标显示在页面顶部，侧边栏同步展示
  - 后端 `Page.icon` 字段已存在
- **A-02 页面标题**：
  - 字号 40px，字重 700，颜色 `#37352f`，无边框 contenteditable
  - 占位符文字："Untitled"（灰色 `#c7c6c3`）
  - `Enter` 键跳到编辑器第一个 block
  - `↓` 键跳到编辑器第一个 block
  - 标题修改后自动同步到侧边栏（防抖 800ms）
- **A-03 内容区宽度**：
  - 最大宽度 900px，水平居中
  - 左右 padding 96px（`max-width: 900px; padding: 0 96px`）
  - 顶部 padding（标题上方）60px

### B. 侧边栏（Sidebar）

#### B-01 整体布局
- 宽度 240px，背景 `#f7f7f5`，右侧 border `rgba(55,53,47,.09)`
- 侧边栏可折叠（点击 ← 按钮收起，留 0 宽度；悬停边缘展开）

#### B-02 侧边栏头部
- 显示 workspace 名称（固定"noteyard"）
- 头部操作图标：新建页面（+）

#### B-03 页面列表项
- 每项高度 28px，padding `2px 8px`
- 结构：`[折叠箭头][icon emoji 或 📄][标题][hover 操作区]`
- 折叠箭头：`▶/▼`，12px，鼠标悬停才显示（无子页面时隐藏）
- 页面 icon：如果 `Page.icon` 非空显示 emoji，否则显示默认页面图标 📄（灰色）
- 标题：13px，`#37352f`，超出省略
- hover 操作区（仅 hover 时显示）：
  - `⋯` 更多操作按钮（弹出菜单：重命名 / 删除）
  - `+` 添加子页面按钮
- 选中项背景 `rgba(55,53,47,.08)`
- hover 背景 `rgba(55,53,47,.04)`

#### B-04 侧边栏底部
- "新建页面"按钮，样式与 Notion 一致：`+ 新建页面`

### C. 编辑器 — 页面标题区

实现独立于 BlockNote 的页面标题编辑区，位于 BlockNote 编辑器上方：
- `contenteditable` 或 `<input>`，样式按 A-02
- 修改触发 `api.pages.update(pageId, { title })`（防抖 800ms）
- 同时触发 sidebar 刷新

### D. 编辑器 — Block 增强

BlockNote 已提供基础块，本期通过 CSS 覆盖对齐 Notion 视觉：

#### D-01 整体编辑区
- 字号 16px，行高 1.6，字体 `-apple-system, "Segoe UI", sans-serif`
- `#37352f` 文字色

#### D-02 标题块（H1/H2/H3）
- H1: 30px，700，margin-top 16px
- H2: 24px，600，margin-top 12px
- H3: 20px，600，margin-top 8px
- 所有 heading 颜色 `#37352f`

#### D-03 引用块（Quote）
- 左侧 3px solid `#37352f` border
- 左 padding 14px
- 文字颜色 `#37352f`，略微 italic 可选

#### D-04 行内代码
- 背景 `rgba(135,131,120,.15)`，圆角 3px，padding `2px 4px`
- 字体 `ui-monospace, monospace`，颜色 `#e03e2f`

#### D-05 代码块
- 背景 `#f7f6f3`，圆角 6px，padding 16px
- 顶部显示语言标签（BlockNote 已支持语言选择器）
- 字体 monospace，14px，颜色 `#37352f`

#### D-06 分割线（Divider）
- `border: none; border-top: 1px solid rgba(55,53,47,.09); margin: 6px 0`

#### D-07 待办事项（To-do / Checkbox）
- checkbox 颜色 `#2383e2`（accent-color）
- 已完成项文字加 `text-decoration: line-through; color: #9b9a97`

#### D-08 列表（Bullet / Numbered）
- Bullet 缩进 24px，bullet 颜色 `#9b9a97`
- Numbered 同样缩进，数字颜色 `#9b9a97`
- 列表项 line-height 1.6

#### D-09 Toggle 块
- 折叠标题旁显示 `▶/▼` 箭头，可点击展开/收起
- BlockNote 原生 toggle 块已支持，CSS 对齐样式

#### D-10 Callout 块（新增）
- 不在本期（BlockNote 无原生 Callout，需要自定义块，工作量较大，后续 REQ）

#### D-11 拖拽手柄
- BlockNote 原生支持，CSS 确保手柄 `⠿` 显示颜色 `#9b9a97`，hover `#37352f`

### E. 数据库增强

#### E-01 Select 列 — 选项管理
- 列头菜单中的 select 类型，增加选项管理入口
- 弹出"选项管理"面板：显示已有选项（带颜色标签）、新增选项、删除选项
- 选项颜色从预设 8 色池选择（与现有 `TAG_COLORS` 一致）
- 编辑单元格时，展示选项下拉列表（不再自由输入）

#### E-02 单元格键盘导航
- `Tab`：移动到右侧单元格，末列时跳到下一行首列
- `Enter`：确认编辑，移动到下方单元格
- `Shift+Tab`：反向移动
- `Escape`：取消编辑，恢复原值

#### E-03 列宽调整
- 列头右侧显示拖拽调整线（拖拽时显示竖线），drag 调整列 `min-width`
- 最小宽度 80px，最大宽度 500px

#### E-04 行内展开（Row Detail）
- 每行行首增加 `↗` 打开按钮（hover 显示）
- 点击弹出行详情 Modal：显示所有字段（列名 + 对应值），可编辑，关闭时保存
