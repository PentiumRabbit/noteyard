## 用户故事

作为 noteyard 用户：
- 我希望能将数据库切换为看板视图，按选择列分组显示卡片，方便管理任务状态
- 我希望在侧边栏拖拽页面来调整顺序和层级，和 Notion 一样直观
- 我希望在编辑器中输入 `@` 后搜索并插入页面链接，实现页面间快速跳转

---

## 功能说明

### 1. 看板视图 (Kanban)

- 数据库视图切换器新增「看板」选项（现有：表格）
- 看板按某一 `select` 列的选项值分组，每组为一列
- 每张卡片展示行的主标题列（第一列）及可配置的其他列
- 支持在列内拖拽卡片调整行 `order_index`
- 支持跨列拖拽，拖动后自动更新该行的 select 列值
- 无 select 列时提示"请先添加单选列以启用看板视图"

### 2. 页面拖拽排序

- 侧边栏页面列表支持拖拽排序（同级排序 + 跨层级移动）
- 拖拽时显示插入位置指示线（Notion 风格）
- 拖拽到另一页面上停留 600ms 自动展开，可放入成为子页面
- 放下后调用接口更新 `order_index` 和 `parent_id`
- 拖拽期间不触发页面选中

### 3. @mention 页面链接

- 编辑器中输入 `@` 触发页面搜索弹窗（与 Cmd+K 搜索复用 UI）
- 选中页面后在光标处插入内联页面链接（显示页面图标 + 标题）
- 点击链接跳转至目标页面（调用 onSelect）
- 链接样式：蓝色下划线，hover 显示页面标题 tooltip

## 验收标准

1. 数据库视图切换器显示"表格"和"看板"两个选项
2. 看板视图按 select 列分组，每组显示对应卡片
3. 看板列内拖拽后 order_index 持久化到后端
4. 看板跨列拖拽后 select 列值持久化到后端
5. 侧边栏页面可拖拽调整同级顺序，order_index 持久化
6. 侧边栏页面可拖拽移动层级，parent_id 持久化
7. 拖拽悬停 600ms 自动展开折叠页面
8. 编辑器 @ 触发搜索，选中后插入内联页面链接
9. 内联页面链接点击可跳转至目标页面
10. 所有新增功能在亮色/暗色主题下均正常显示
