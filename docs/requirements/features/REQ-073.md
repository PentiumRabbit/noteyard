## 背景

REQ-072 实现了内容导出为 Markdown/JSON。本 REQ 实现反向操作：用户可以将 `.md` 文件导入为 noteyard 页面，方便从其他工具（Obsidian、Typora、Notion 导出等）迁移内容。

---

| 功能 | 本 REQ | 说明 |

| 单文件 .md 导入为新页面 | ✅ | 文件名作为页面标题，Markdown 内容转 BlockNote 块 |
| 前端上传入口（侧边栏或设置页） | ✅ | |

## 场景矩阵

| # | 场景 | 操作 | 预期结果 |
|---|------|------|---------|
| 1 | 导入基础 Markdown | 上传含标题、段落、列表的 .md | 创建新页面，标题=文件名（去 .md 后缀），内容对应 BlockNote 块 |
| 2 | 标题行（# ## ###） | `# H1`, `## H2`, `### H3` | 转为 heading1/2/3 块 |
| 3 | 列表 | `- item`, `1. item`, `- [ ]`, `- [x]` | 转为 bulletListItem/numberedListItem/checkListItem 块 |
| 4 | 引用块 | `> text` | 转为 quote 块 |
| 5 | 代码块 | ` ```lang\ncode\n``` ` | 转为 code 块，language 属性保留 |
| 6 | 分隔线 | `---` | 转为 divider 块 |
| 7 | 内联样式 | `**bold**`, `*italic*`, `~~strike~~`, `` `code` `` | 内联样式正确映射 |
| 8 | 链接 | `[text](url)` | 转为带 href 的 link 内联内容 |
| 9 | 空文件 | 上传空 .md | 创建标题为文件名的空页面，不报错 |
| 10 | 非 .md 文件 | 上传 .txt 或 .jpg | 返回 400 错误，不创建页面 |
| 11 | 文件过大 | 上传 > 5MB | 返回 413 错误 |
| 12 | 导入成功后跳转 | 导入完成 | 前端自动导航到新建页面 |

## 技术方案

### T1 — 后端：Markdown 导入 API

`POST /api/import/markdown`

- `multipart/form-data`，字段名 `file`，限 5MB
- 取文件名（去 `.md` 后缀）为页面标题
- 解析 Markdown 文本，生成 blocks，调用 `PageRepository.Create` + `BlockRepository.Create`（逐块插入，或用 `BlockRepository.BatchUpdate` 若接口支持）
- 返回新建页面的 `id`

**Markdown → Block 转换规则（Go 层，goldmark 库）：**

使用 `github.com/yuin/goldmark` 解析 Markdown AST，遍历 AST 节点转为 Block：

| Markdown AST 节点 | Block 类型 | content/props |
|-------------------|------------|---------------|
| Heading（level 1/2/3） | heading1/2/3 | 内联内容 JSON |
| Paragraph | paragraph | 内联内容 JSON |
| ListItem（bullet） | bulletListItem | 内联内容 JSON |
| ListItem（ordered） | numberedListItem | 内联内容 JSON |
| ListItem（task, unchecked） | checkListItem | content=内联, props=`{"checked":false}` |
| ListItem（task, checked） | checkListItem | content=内联, props=`{"checked":true}` |
| Blockquote | quote | 内联内容 JSON |
| FencedCodeBlock | code | content=纯文字, props=`{"language":"lang"}` |
| ThematicBreak | divider | content=`[]`, props=`{}` |

**内联节点 → BlockNote InlineContent JSON：**

| goldmark 内联节点 | BlockNote 格式 |
|------------------|---------------|
| Text | `{"type":"text","text":"...","styles":{}}` |
| Emphasis（1层） | styles.italic=true |
| Emphasis（2层/strong） | styles.bold=true |
| Strikethrough | styles.strike=true |
| CodeSpan | styles.code=true |
| Link | `{"type":"link","href":"url","content":[...]}` |

**依赖：** `github.com/yuin/goldmark`（已是 Go 生态标准 Markdown 库，无许可证问题）。若 go.mod 中未引入，`go get github.com/yuin/goldmark`。

### T2 — 前端：导入入口

在侧边栏底部或"新建页面"按钮附近添加"导入 Markdown"按钮（或文件选择 input）：

```typescript
// 触发文件选择
<input type="file" accept=".md" onChange={handleImport} style={{display:'none'}} ref={fileInputRef} />
<button onClick={() => fileInputRef.current?.click()}>导入 Markdown</button>
```

`handleImport`：
1. 构造 FormData，append file
2. `POST /api/import/markdown`
3. 成功后从响应拿到 `page_id`，调用现有的页面导航函数跳转到新页面
