## 背景与目标

当前欢迎页（`seeds/welcome.json`）以文字描述各块类型的用法，读者无法直观感知块的实际外观和交互效果。

目标：将欢迎页改版为"块类型展示台"——类似 Notion 的 Getting Started 页面，每种支持的块类型都有实际可见的示例块出现在页面中，用户看到即知道效果，无需先创建再体验。

**仅修改 `welcome.json` 的 `blocks` 数组内容，page 元数据（id、title、icon、order_index）保持不变。**

## 支持的块类型清单

以下块类型从 `Editor.tsx` 的 schema 注册与斜杠菜单配置中提取，共 19 种：

### BlockNote 默认块（`defaultBlockSpecs`）

| 类型 | 中文名 | 说明 |
|------|--------|------|
| `paragraph` | 段落 | 普通文本段落 |
| `heading` | 标题 | H1 / H2 / H3 三级 |
| `bulletListItem` | 无序列表 | 圆点列表项，支持缩进嵌套 |
| `numberedListItem` | 有序列表 | 数字列表项，支持缩进嵌套 |
| `checkListItem` | 任务列表 | 带勾选框的列表项 |
| `codeBlock` | 代码块 | 等宽代码展示，支持语言标注 |
| `image` | 图片 | 上传或粘贴图片（欢迎页跳过实际示例，见下文） |
| `table` | 表格 | 原生行列表格 |

### 自定义块

| 类型 | 中文名 | 说明 |
|------|--------|------|
| `horizontalRule` | 分割线 | 水平分隔线 |
| `quote` | 引用 | 左边框引用块 |
| `callout` | 标注 | 带 emoji 图标的高亮提示块 |
| `toggle` | 折叠块 | 可展开/收起的内容块 |
| `database` | 数据库 | 内嵌结构化表格（展示空数据库即可） |
| `subpage` | 子页面 | 嵌入子页面链接块 |
| `fileAttach` | 文件附件 | 上传文件并展示下载链接 |
| `bookmark` | 书签 | 网页链接预览卡片 |
| `embed` | 嵌入 | iframe 嵌入外部网页 |
| `pdf` | PDF 预览 | 上传并内嵌预览 PDF |
| `button` | 按钮 | 可点击的交互按钮块 |

### 多列布局（xl-multi-column）

| 类型 | 中文名 | 说明 |
|------|--------|------|
| `columnList` + `column` | 并排布局 | 左右多列容器，column 为 columnList 的直接子块 |

## 页面结构设计

欢迎页按如下分节组织，每节含标题（H2）+ 实际示例块 + 必要说明。

### 节 1：页面开头

- H1 标题：「欢迎使用 noteyard 👋」
- callout（📝）：应用一句话介绍

### 节 2：文字与段落

展示基础文本块：

- paragraph：含加粗、斜体、下划线、删除线、行内代码等格式的混合段落
- H1 / H2 / H3：各级标题示例（以 H3 示例紧接段落之后）
- quote：一条引用

### 节 3：列表

- bulletListItem：3 条无序列表，第 2 条有一级缩进子项
- numberedListItem：3 条有序列表
- checkListItem：3 条任务列表，1 条已勾选、2 条未勾选

### 节 4：代码

- codeBlock：一段示例代码（JavaScript，约 5 行）

### 节 5：标注与分割

- callout（💡）：一条提示型标注
- callout（⚠️）：一条警告型标注
- horizontalRule：分割线示例

### 节 6：折叠块

- toggle：1 个折叠块，标题"点击展开查看详情"，内容为一条段落说明折叠块用途

### 节 7：表格

- table：3 列 × 3 行（含表头行），演示姓名/角色/状态类数据

### 节 8：并排布局

- columnList 容器，内含 2 个 column：
  - 左列：1 个 paragraph（介绍左列内容）
  - 右列：1 个 paragraph（介绍右列内容）
- 紧随一条 callout 说明如何操作拖拽分栏

### 节 9：媒体块

- image：跳过实际示例，改为 callout（📷）说明图片块的插入方式（输入 `/图片` 或直接粘贴）
- bookmark：提供一个真实可访问的书签示例（如 `https://noteyard.app`，title 和 description 填写固定文案）
- embed：callout 说明嵌入块需粘贴支持 iframe 的网址
- pdf：callout 说明 PDF 块需上传文件后展示预览
- fileAttach：callout 说明文件附件块的上传方式

### 节 10：交互块

- button：2 个按钮示例
  - 蓝色无动作按钮，标签"示例按钮"
  - 绿色打开链接按钮，标签"访问官网"，url 为 `https://noteyard.app`

### 节 11：数据库

- database：一个空数据库块（databaseId 预留占位，由实现层在 seed 加载时创建空数据库）
- callout（🗃️）说明数据库块支持添加列、新建行、字段类型等操作

### 节 12：子页面

- subpage：1 个子页面链接块（pageId 为空字符串占位，title 填"示例子页面"，icon 📄）
- callout 说明子页面块点击可跳转

### 节 13：尾部

- horizontalRule
- quote（斜体）：结语文案，与当前版本保持一致

## welcome.json 修改说明

### 修改范围

只修改 `blocks` 数组的内容。以下字段**不变**：

```json
{
  "version": 1,
  "page": {
    "id": "00000000-0000-0000-0000-000000000001",
    "title": "欢迎使用 noteyard",
    "icon": "👋",
    "order_index": 0
  }
}
```

### block ID 命名规则

继续使用 `00000000-0000-0000-0001-XXXXXXXXXXXX` 格式，编号从 `000000000001` 顺序递增，不复用已有 ID，不跳号。

### 各块类型的 JSON 字段格式

以下格式从现有 welcome.json 和 REQ-070 中学习并扩展：

**paragraph**
```json
{
  "id": "00000000-0000-0000-0001-XXXXXXXXXXXX",
  "type": "paragraph",
  "content": "段落文字"
}
```

**paragraph（含 inline 格式）**
```json
{
  "id": "...",
  "type": "paragraph",
  "content": [
    {"type": "text", "text": "普通 ", "styles": {}},
    {"type": "text", "text": "加粗", "styles": {"bold": true}},
    {"type": "text", "text": " 斜体", "styles": {"italic": true}}
  ]
}
```

**heading**
```json
{
  "id": "...",
  "type": "heading",
  "props": {"level": 2, "textColor": "default", "backgroundColor": "default", "textAlignment": "left"},
  "content": "标题文字"
}
```

**bulletListItem / numberedListItem**
```json
{
  "id": "...",
  "type": "bulletListItem",
  "content": "列表项文字"
}
```

**checkListItem**
```json
{
  "id": "...",
  "type": "checkListItem",
  "props": {"checked": false},
  "content": "任务项文字"
}
```

**codeBlock**
```json
{
  "id": "...",
  "type": "codeBlock",
  "props": {"language": "javascript"},
  "content": "// 示例代码\nfunction greet(name) {\n  return `Hello, ${name}!`;\n}\nconsole.log(greet('noteyard'));"
}
```

**quote**
```json
{
  "id": "...",
  "type": "quote",
  "content": "引用文字"
}
```

**callout**
```json
{
  "id": "...",
  "type": "callout",
  "props": {"icon": "💡"},
  "content": "标注文字"
}
```

**horizontalRule**
```json
{
  "id": "...",
  "type": "horizontalRule"
}
```

**toggle**
```json
{
  "id": "...",
  "type": "toggle",
  "props": {"open": "true", "summary": "点击展开查看详情"},
  "content": "这是折叠块内的内容，收起后不可见。"
}
```

**table**（content 为原生 BlockNote table 格式）
```json
{
  "id": "...",
  "type": "table",
  "content": {
    "type": "tableContent",
    "rows": [
      {"cells": [
        [{"type": "text", "text": "姓名", "styles": {"bold": true}}],
        [{"type": "text", "text": "角色", "styles": {"bold": true}}],
        [{"type": "text", "text": "状态", "styles": {"bold": true}}]
      ]},
      {"cells": [
        [{"type": "text", "text": "Alice", "styles": {}}],
        [{"type": "text", "text": "设计师", "styles": {}}],
        [{"type": "text", "text": "在职", "styles": {}}]
      ]},
      {"cells": [
        [{"type": "text", "text": "Bob", "styles": {}}],
        [{"type": "text", "text": "工程师", "styles": {}}],
        [{"type": "text", "text": "在职", "styles": {}}]
      ]}
    ]
  }
}
```

**columnList / column**（嵌套结构，遵循 REQ-070 格式）
```json
{
  "id": "...",
  "type": "columnList",
  "children": [
    {
      "id": "...",
      "type": "column",
      "children": [
        {"id": "...", "type": "paragraph", "content": "左列：可以放任意块"}
      ]
    },
    {
      "id": "...",
      "type": "column",
      "children": [
        {"id": "...", "type": "paragraph", "content": "右列：将块拖到另一块的左/右边缘即可分栏"}
      ]
    }
  ]
}
```

**bookmark**
```json
{
  "id": "...",
  "type": "bookmark",
  "content": {
    "url": "https://noteyard.app",
    "title": "noteyard — 本地优先的块编辑器",
    "description": "像 Notion 一样组织知识，数据完全存储在本地。",
    "favicon": ""
  }
}
```

说明：bookmark 块的 props 在 DB 中以 `content` 字段存储（见 Editor.tsx `buildDtosRecursive` 逻辑），seed 中以 `content` 对象描述，实现层负责序列化处理。

**button**
```json
{
  "id": "...",
  "type": "button",
  "content": {
    "label": "示例按钮",
    "color": "blue",
    "action": "none",
    "url": ""
  }
}
```

说明：button 块与 bookmark 同属"props 写入 DB content 字段"的特殊块类型（见 Editor.tsx），seed 中以 `content` 对象描述。

**database**
```json
{
  "id": "...",
  "type": "database",
  "content": {
    "databaseId": ""
  }
}
```

说明：databaseId 为空时，实现层需在 seed 加载期间自动创建一个空数据库并回填 databaseId，或将数据库块保留为空状态（页面打开后用户可点击初始化）。具体处理方式由实现层决定，PM 不约束。

**subpage**
```json
{
  "id": "...",
  "type": "subpage",
  "content": {
    "pageId": "",
    "title": "示例子页面",
    "icon": "📄"
  }
}
```

说明：subpage 块 pageId 为空时渲染为不可跳转的占位链接；若实现层支持在 seed 中创建子页面，可进一步完善，不做强制要求。

## 不在范围内

- **图片块（image）实际示例**：图片块需要真实文件 URL，seed 中无法内嵌，用 callout 说明插入方式替代
- **embed / pdf / fileAttach 实际文件**：同上，需要真实文件，用 callout 说明替代
- **数据库块预置行列数据**：只展示空数据库（或初始化提示状态），不预置样本数据
- **subpage 创建真实子页面**：seed 格式不支持同时创建子页面，pageId 留空占位
- **欢迎页设为只读**：用户可自由编辑/删除欢迎页内容，与当前行为保持一致
- **page 元数据变更**：title、icon、id、order_index 不修改
- **多语言版本**：只维护中文版本

## 验收标准

- [ ] 全新数据库启动后，欢迎页包含以下块类型的实际示例：paragraph（含内联格式）、H1/H2/H3、bulletListItem、numberedListItem、checkListItem、codeBlock、quote、callout、horizontalRule、toggle、table、columnList/column、bookmark、button
- [ ] image、embed、pdf、fileAttach、subpage 块各有一条 callout 说明其插入/使用方式
- [ ] database 块出现在页面中（空状态或初始化占位均可）
- [ ] 所有块在编辑器中正常渲染，无报错
- [ ] 欢迎页内容可被用户自由编辑和删除（非只读）
- [ ] `page` 字段（id、title、icon、order_index）与改版前保持一致
- [ ] block ID 均遵循 `00000000-0000-0000-0001-XXXXXXXXXXXX` 格式，无重复
- [ ] 已有旧数据库（欢迎页 id 已存在）启动后，seed 幂等跳过，不覆盖用户已有内容
