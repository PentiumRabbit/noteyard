# REQ-040: 主题切换

**类型**: 功能增强
**优先级**: P2
**提出日期**: 2026-04-30
**状态**: 📋 待确认（等待 N1）

## 用户故事

作为 noteyard 用户，我希望能够在多套视觉主题之间自由切换，以便根据使用场景（白天工作、夜间护眼、长文写作、个性化风格）选择最适合自己的界面风格，且偏好在下次打开时自动恢复。

## 主题选项定义

| # | 主题名称 | 英文标识 | 类型 | 色调描述 |
|---|---------|---------|------|---------|
| 1 | 默认亮色 | `default-light` | 本地 | 白色背景，深灰文字，Notion 经典风格，高对比度 |
| 2 | 暗色 | `dark` | 本地 | 深灰/近黑背景，浅灰文字，护眼，类 Notion Dark |
| 3 | 暖米色 | `warm` | 本地 | 米黄/奶油色背景，棕灰文字，纸张质感，适合长文写作 |
| 4 | 极光 | `aurora` | 网络 | 深紫渐变背景，霓虹青/紫强调色，赛博朋克风格 |
| 5 | 森林 | `forest` | 网络 | 深绿色系背景，自然橄榄/苔绿调，沉静自然感 |

> 网络主题（极光、森林）选中后从 CDN 动态加载 CSS 文件，需标注「需联网」标识。

## 实现机制说明

### 1. CSS 变量体系

所有颜色通过 CSS 自定义属性（变量）控制，核心变量包括但不限于：

```
--color-bg-primary       页面主背景
--color-bg-secondary     侧边栏/面板背景
--color-bg-hover         悬浮态背景
--color-text-primary     主文字
--color-text-secondary   辅助/占位文字
--color-accent           强调色（链接、按钮、高亮）
--color-border           分隔线/边框
--color-surface          卡片/弹窗表面色
```

### 2. data-theme 切换机制

- 本地主题：在 `<html>` 元素上设置 `data-theme="<标识>"` 属性，对应 CSS 文件中的主题变量块即生效，无需加载外部资源。
- 切换时无页面刷新，样式即时过渡（`transition: background-color 0.2s, color 0.2s`）。

### 3. 网络主题按需加载

- 用户首次选择网络主题时，动态插入 `<link rel="stylesheet" href="<CDN-URL>">` 标签。
- 监听 `link.onload` 事件，加载完成后再切换 `data-theme`，避免主题闪烁。
- 已加载的外部 CSS 缓存在 DOM 中，再次切换该主题无需重新请求。

### 4. 偏好持久化

- 用户选择的主题标识写入 `localStorage`（key: `noteyard_theme`）。
- 应用启动时优先读取该值，无值则默认使用 `default-light`。

### 5. 断网降级

- 网络主题加载失败（`link.onerror` 或超时）时，自动降级为 `default-light`，并显示提示：「主题加载失败，已切换至默认亮色」。
- 断网状态下主题选择面板中网络主题显示「需联网」灰色标注，可点击但会触发降级流程。

## 场景矩阵

| # | 场景 | 用户行为 | 预期结果 |
|---|------|---------|---------|
| 1 | 切换本地主题 | 打开主题面板，点击「暗色」 | 界面即时切换为深色风格，无页面刷新，动画过渡流畅 |
| 2 | 切换网络主题（联网） | 点击「极光」主题 | 显示加载状态，CSS 加载完成后界面切换为深紫极光风格 |
| 3 | 切换网络主题（断网） | 断网情况下点击「森林」主题 | 加载失败，提示「主题加载失败，已切换至默认亮色」，界面保持亮色 |
| 4 | 偏好持久化 | 切换为「暖米色」后关闭并重新打开应用 | 重新打开时自动应用暖米色主题，无需再次选择 |
| 5 | 重复切换网络主题 | 选极光 → 选森林 → 再选极光 | 已缓存的极光 CSS 不重新请求，直接切换，速度明显更快 |
| 6 | 主题面板标注识别 | 打开主题选择面板 | 本地主题无额外标注，网络主题显示「需联网」标识 |
| 7 | 默认启动状态 | 首次使用（无 localStorage 记录） | 默认展示「默认亮色」主题，与现有白色 Notion 风格一致 |
| 8 | 主题与编辑器兼容 | 在暗色主题下编辑文档、使用斜杠菜单 | 编辑器内容、斜杠菜单、工具栏均正确应用暗色主题变量 |

## 验收标准

- [ ] 5 套主题均可在主题选择面板中展示并选中
- [ ] 本地主题（默认亮色、暗色、暖米色）切换即时生效，无页面刷新
- [ ] 网络主题（极光、森林）在联网时可正常加载并切换
- [ ] 网络主题选项显示「需联网」标识
- [ ] 断网时选择网络主题触发降级，显示失败提示并回退至默认亮色
- [ ] 主题偏好写入 localStorage，刷新/重启后自动还原
- [ ] 无 localStorage 记录时默认使用 `default-light`
- [ ] 主题切换包含颜色过渡动画（≤ 200ms）
- [ ] 编辑器、侧边栏、弹窗、数据库视图等所有区域均响应主题变量
- [ ] 已加载的网络主题 CSS 在同会话中不重复请求
