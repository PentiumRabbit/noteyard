# BUG-001: 编辑器内容区域空白——块列表不渲染

**类型**: Bug
**优先级**: P0（阻断主流程）
**提出日期**: 2026-04-30
**状态**: 📋 待确认（等待 N1）
**关联版本**: REQ-035 实现后引入

---

## 问题描述

打开任意页面后，编辑器内容区域一片空白，仅显示页面大标题（Page Title）。页面内所有块（段落、标题、列表、引用、分隔线等）均不渲染，用户无法查看或编辑任何内容。

---

## 复现步骤

1. 启动 noteyard 前后端服务
2. 在侧边栏点击任意已有页面（含至少一个块）
3. 观察编辑器区域：仅显示页面大标题，块内容为空
4. 打开浏览器开发者工具 → Network，检查 `GET /api/pages/{id}/blocks` 响应
5. 打开 Console，观察是否有 JS 错误

---

## 根因假设

（留给架构师展开分析，PM 不预设结论）

- `toBlockNote()` 转换逻辑在 REQ-035 后返回格式与 BlockNote 期望不符
- `editor.replaceBlocks()` 调用时机或参数异常（如 editor 实例未就绪）
- REQ-035 新增的块类型（封面、引用、分隔线）引入的数据结构变更破坏了旧块的映射
- 后端 `GET /api/pages/{id}/blocks` 响应结构变更，前端未同步适配

## 验收标准

1. **基础渲染**：打开任意已有页面，编辑器正确渲染所有块，包括段落、标题（H1~H3）、有序列表、无序列表
2. **REQ-035 块类型**：引用块、分隔线在编辑器中正常显示，与 Notion 视觉保持一致
3. **数据一致性**：渲染内容与 `GET /api/pages/{id}/blocks` 接口返回数据一致，无静默丢失
4. **无 Console 报错**：编辑器加载过程中浏览器 Console 无 Error 级别输出
5. **空页面兼容**：块列表为空时，编辑器显示空白可输入状态，不崩溃
6. **回归 REQ-035**：REQ-035 所有已实现功能（封面、面包屑、数据库排序/筛选/隐藏列、多选列）验证通过，无功能倒退
