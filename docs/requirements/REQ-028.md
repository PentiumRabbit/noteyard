# REQ-028: Database 块 — 后端数据层

**类型**: 功能扩展
**优先级**: P1
**提出日期**: 2026-04-30
**状态**: ✅ 已关闭

---

## 用户故事

作为 noteyard 用户，我希望能在页面中插入类似 Notion 的数据库表格块，支持自定义列类型和公式计算，以便在编辑器内管理结构化数据。

---

## 一期范围

本期只交付后端数据层（数据库表 + API），前端自定义块下一期。

---

## 列类型

| 类型 | 说明 |
|------|------|
| `text` | 纯文本 |
| `number` | 数字 |
| `checkbox` | 布尔值（true/false） |
| `select` | 单选，选项列表存在列定义中 |
| `date` | 日期（ISO 8601 字符串） |
| `formula` | 引用同行其他列计算，表达式格式 `{列名}` |

---

## 场景矩阵

| 维度 | 场景 | 预期行为 |
|------|------|---------|
| 创建 database | 关联已有 block | database 元信息写入，返回完整结构 |
| 添加列 | 普通列类型 | 列定义写入，后续新行自动含该列 |
| 添加列 | formula 列，无循环引用 | 正常写入 |
| 添加列 | formula 列，存在循环引用 | 返回 400，拒绝写入 |
| 添加行 | 空行 | 行记录写入，cells 为空 |
| 更新单元格 | 批量更新同一行多个 cell | upsert，返回 204 |
| 查询行列表 | 含 formula 列 | 返回时服务端计算 formula 值，不存储结果 |
| 删除列 | 含数据的列 | 级联删除所有 cells，返回 204 |
| 删除行 | 含数据的行 | 级联删除所有 cells，返回 204 |
| 删除 database | 含行列数据 | 级联全部删除，返回 204 |

---

## 验收标准

- [ ] migration 可幂等执行，不破坏已有数据
- [ ] 所有 API 端点返回正确状态码
- [ ] formula 循环引用检测有效（curl 验证）
- [ ] formula 值在 GET rows 时正确计算返回
- [ ] 级联删除经 curl 验证
