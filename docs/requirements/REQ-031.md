**类型**: 功能增强

## 用户故事

作为 noteyard 用户，我希望能在 formula 列中编辑公式，公式可引用同行其他列的值并自动计算，体验与 Notion 一致。

---

## 功能范围

### 本期
- formula 列头菜单增加"编辑公式"入口
- 公式编辑弹层：显示当前公式、可引用列列表
- 公式语法：`prop("列名")` 引用列，支持 `+ - * /` 运算
- 前端计算：保存公式到列 `formula` 字段，所有行实时计算展示
- 公式预览：弹层内显示第一行计算结果
- 错误处理：语法/引用错误时弹层提示，不保存

### 不在本期
- 聚合函数（sum / count / avg）
- 公式自动补全 / 高亮
- 跨行引用
- 条件函数（if / ternary）

---

## 验收标准

- [x] formula 列头菜单出现"编辑公式"按钮
- [x] 弹层显示当前公式和可引用列名
- [x] 输入 `prop("Q1销售额") + prop("Q2销售额")` 后预览正确
- [x] 保存后所有行 formula 列自动重新计算
- [x] 引用不存在列时显示 `—`
- [x] 公式语法错误时提示错误（⚠），不保存
