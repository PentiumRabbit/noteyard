# REQ-038: 侧边栏交互增强

**类型**: UI 增强
**优先级**: P1
**提出日期**: 2026-04-30
**状态**: ✅ 已完成

---

## 用户故事

作为 noteyard 用户，我希望侧边栏提供完整的页面管理交互，包括右键菜单操作、行内重命名、折叠收起、图标显示和底部快速新建，使日常导航与页面管理操作无需离开侧边栏即可完成。

---

## 场景矩阵

| # | 场景 | 用户行为 | 预期结果 |
|---|------|---------|---------|
| 1 | 右键菜单 — 弹出 | 右键单击侧边栏任意页面条目 | 弹出包含「重命名」和「删除」的上下文菜单 |
| 2 | 行内重命名 — 确认 | 右键 → 重命名，修改名称后按 Enter | 页面标题更新，退出编辑态，侧边栏实时刷新 |
| 3 | 行内重命名 — 取消 | 右键 → 重命名，修改名称后按 Escape | 放弃修改，恢复原标题，退出编辑态 |
| 4 | 删除确认 — 确认 | 右键 → 删除，中文确认框点击「确定」 | 页面从侧边栏和数据库中删除 |
| 5 | 删除确认 — 取消 | 右键 → 删除，中文确认框点击「取消」 | 操作中止，页面保留不变 |
| 6 | 侧边栏折叠 | 点击头部收起按钮 | 侧边栏收起，仅显示展开箭头，内容区自动扩展 |
| 7 | 侧边栏展开 | 折叠状态下点击展开箭头 | 侧边栏恢复完整显示，页面列表可见 |
| 8 | 页面图标显示 | 查看侧边栏页面列表 | 每个页面条目左侧展示对应 emoji 图标 |
| 9 | 底部新建按钮 | 点击侧边栏底部「新建页面」按钮 | 创建新页面并在侧边栏中追加显示 |

---

## 验收标准

- [x] 右键单击页面条目弹出上下文菜单，包含「重命名」和「删除」两项
- [x] 重命名通过行内输入框触发，Enter 确认保存，Escape 取消还原
- [x] 删除操作触发中文确认对话框，用户确认后方可执行删除
- [x] 侧边栏头部提供收起按钮，折叠后仅保留展开箭头占位
- [x] 折叠状态下点击展开箭头可恢复侧边栏完整显示
- [x] 侧边栏每个页面条目显示页面 icon（emoji）
- [x] 侧边栏底部固定显示「新建页面」按钮，点击即可创建页面
