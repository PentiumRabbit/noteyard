## 待修复问题清单

### P0 — 紧急

#### I-001 DatabaseView useEffect 竞态
- **文件**：`web/src/components/database/DatabaseView.tsx` / 408–454
- **问题**：`useEffect` 依赖数组 eslint-disable，`relationRowsCache` 闭包竞态，旧缓存被新 effect 覆盖，视图闪回空值
- **建议方向**：将 relation 批量加载抽取为 `useCallback`，正确声明依赖；或用 `useRef` 保存缓存避免闭包捕获过期值

#### I-002 API 错误处理缺失
- **文件**：`web/src/api/client.ts` / 5–17，App.tsx L80–83，DatabaseView.tsx L397–404，Sidebar.tsx L178–181
- **问题**：`req<T>` 正确抛出，但所有调用方用 `void` 前缀静默丢弃 Promise rejection，用户不收到任何错误提示
- **建议方向**：在 api/client 层集成全局错误 toast（如 react-hot-toast），或通过 React Context 提供 `onError` 回调

#### I-003 toBlockNote 静默丢失数据
- **文件**：`web/src/utils/toBlockNote.ts` / 4–90，Editor.tsx L731，L750–751
- **问题**：JSON.parse 失败时置空无 warn，`toBlockNote` 返回 `any[]`，Editor 内 replaceBlocks 的 catch 块完全静默
- **建议方向**：解析失败时 `console.warn` 记录 blockId 和原始内容；为 `toBlockNote` 添加明确返回类型；Editor replaceBlocks catch 块记录错误日志

### P1 — 重要

#### I-006 TAG_COLORS/parseOptions 重复
- **文件**：`web/src/components/database/KanbanView.tsx` L16–25 / `web/src/components/database/DatabaseView.tsx` L93–102
- **问题**：`TAG_COLORS` 数组逐字段完全相同地重复定义；`parseOptions` 在两处实现近乎相同
- **建议方向**：提取到 `web/src/utils/tagColors.ts` 或 `web/src/components/database/shared.ts`

#### I-007 parseFileAttachments 重复
- **文件**：`web/src/components/database/GalleryView.tsx` L12–19 / `web/src/components/database/DatabaseView.tsx` L25–33
- **问题**：`parseFileAttachments` 函数逐字节相同地重复定义
- **建议方向**：提取到 `web/src/utils/fileAttachments.ts`

#### I-008 Editor 内硬编码 localhost URL
- **文件**：`web/src/components/editor/Editor.tsx` / 267–294，312–319，434–438
- **问题**：`FileAttachBlock`、`BookmarkBlock`、`PdfBlock` 内直接硬编码 `"http://localhost:8080/api/..."` 绕过统一 api/client 层
- **建议方向**：抽取 `api.uploads.upload(file)` 和 `api.meta.fetch(url)` 方法，或至少将 BASE_URL 提取为模块级常量

#### I-009 column overlay DOM 泄漏
- **文件**：`web/src/components/editor/Editor.tsx` / 799–882
- **问题**：组件在 drag 进行中卸载时，`columnOverlayRef.current.remove()` 可能操作已卸载组件遗留 DOM 节点；私有 API `_tiptapEditor` 访问无保护
- **建议方向**：`hideOverlay` 中增加 `isConnected` 检查；私有 API 访问封装为 try/catch 并记录警告

#### I-011 Tauri sidecar 无崩溃感知
- **文件**：`src-tauri/src/lib.rs` / 12–65
- **问题**：`_rx` 被丢弃，sidecar 崩溃后 Tauri 无感知；`on_window_event` 仅在 `Destroyed` 时 kill child，异常退出可能留孤儿进程
- **建议方向**：后台线程监听 `_rx`；sidecar 异常退出时通过 Tauri dialog 提示用户并设置重试上限；用 `on_exit` handler 覆盖所有异常退出路径

#### I-012 Block 类型链路 any 泛滥
- **文件**：`web/src/types/index.ts` L1–11，`web/src/components/editor/Editor.tsx`（≥15 处 eslint-disable）
- **问题**：`Block.content`/`props` 为 `string`，整条数据流缺少类型化中间层，`any` 在链路各处传播
- **建议方向**：为 BlockNote 内容格式定义 TypeScript 接口（`BNBlock`、`BNInlineContent`）；审查 `Block.content` 是否可改为 `unknown` 并在解析时添加 runtime validation

#### I-013 PageItem/PageItemWithRename 重复组件
- **文件**：`web/src/components/sidebar/Sidebar.tsx` / 540–675，L68
- **问题**：`PageItem` 和 `PageItemWithRename` 几乎完全相同，仅差 `renameTrigger` prop；全局 CustomEvent 通信绕过 React 数据流
- **建议方向**：合并为一个组件，通过 `renameRequested?: boolean` prop 触发重命名；用 Zustand/Context 替换全局 CustomEvent

### P2 — 建议

#### I-016 settingsStore 耦合
- **文件**：`web/src/settings/settingsStore.ts`，`web/src/components/editor/Editor.tsx` L34
- **问题**：Editor 引用 `useSettings` 仅为 `themeId`，但与整个设置上下文耦合
- **建议方向**：纯工具函数拆到 `settingsUtils.ts`；Editor 只 subscribe `themeId`

#### I-017 useMonthNav 重复
- **文件**：`web/src/components/database/CalendarView.tsx` L32–41 / `web/src/components/database/TimelineView.tsx` L21–39
- **问题**：月份导航逻辑（year/month 状态 + prevMonth/nextMonth 函数）逐行相同
- **建议方向**：提取 `useMonthNav()` 自定义 hook

#### I-018 封面图 Base64 存 SQLite
- **文件**：`web/src/App.tsx` / 137–151（`handleChangeCover`）
- **问题**：图片 Base64 DataURL 直接存入 `page.cover` SQLite 字段，膨胀数据库体积，影响侧边栏加载性能
- **建议方向**：封面图走 `/api/uploads` 存储为文件，`cover` 字段只存 URL

#### I-019 findPageFlat 多余 / magic literal
- **文件**：`web/src/utils/toBlockNote.ts` L85–89，`Sidebar.tsx` L534–536
- **问题**：`findPageFlat` 是对 `findPage` 的无意义单行包装；`toBlockNote.ts` 中 block type 字符串为 magic literal
- **建议方向**：删除 `findPageFlat`；将 block type 字符串定义为 enum 或 `as const`

#### I-020 loadAvailableDatabases O(n) 请求
- **文件**：`web/src/components/database/DatabaseView.tsx` / 617–638
- **问题**：三层嵌套请求枚举所有数据库，O(pages × blocks_per_page)；缓存无失效机制
- **建议方向**：后端添加 `GET /api/databases` 接口（需与后端架构师对齐）；或每次打开 addColPopover 时清空缓存

#### I-022 commitEdit 乐观更新缺失
- **文件**：`web/src/components/database/DatabaseView.tsx` / 473–482
- **问题**：`commitEdit` 不等待 reload 就清除 `editingCell`，单元格短暂回到旧值后再切换新值，出现视觉闪烁
- **建议方向**：`commitEdit` 后立即在本地 `rows` state 中更新对应 cell 值，后台 reload；失败时回滚
