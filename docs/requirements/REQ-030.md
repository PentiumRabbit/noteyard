## 用户故事

作为 noteyard 用户，我希望数据库表格块的外观和操作方式与 Notion 保持一致，以便获得熟悉的使用体验。

---

## 功能范围

### 样式对齐
- 去掉外边框，改为无边框平铺设计
- 列头使用列类型图标（Text / Number / Checkbox / Date / Formula）
- 行高固定，单元格内容垂直居中
- 行 hover 时整行高亮（淡灰背景）
- `+ 新建` 按钮嵌在表格底部最后一行

### 交互对齐
- 列头点击弹出操作菜单（改名 / 修改类型 / 删除列）
- 行删除按钮仅在 hover 时显示
- select 列的值用彩色 tag 样式展示
- 数据库标题可直接点击 inline 编辑
- 添加列按钮（`+`）在最右侧列头，灰色图标样式

## 不在本期范围
- 看板 / 日历 / 列表视图切换
- 列宽拖拽调整
- 行筛选 / 排序
- 属性面板

## 场景矩阵

| 维度 | 场景 | 预期行为 |
|------|------|---------|
| 列头菜单 | 点击列头 | 弹出菜单：改名 / 类型 / 删除 |
| 列头菜单 | 点击改名 | 列头变为 input，回车确认 |
| 列头菜单 | 点击删除 | 确认后删除列 |
| 行删除 | hover 行 | 最左侧出现删除图标 |
| 行删除 | 点击删除图标 | 删除该行 |
| select 值 | 单元格有值 | 显示彩色 tag |
| 标题编辑 | 点击标题 | 变为 input，失焦保存 |
| 添加列 | 点击列头 + | 弹出列名 + 类型输入，确认后添加 |
| 添加行 | 点击底部 + 新建 | 新行追加到末尾 |
| 空 database | 无列无行 | 显示引导文字"添加第一列" |
