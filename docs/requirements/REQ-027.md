# REQ-027: noteyard 一期核心编辑功能

**类型**: 新项目 / 功能
**优先级**: P0
**提出日期**: 2026-04-30
**状态**: 实现中

---

## 用户故事

作为一个本地知识管理用户，我希望有一个运行在本地的 Notion 替代品，以便在不依赖云服务的情况下管理我的页面和笔记。

---

## 模块拆分（L1 PM → L2 PM × 4）

| 模块 | 负责 L2 PM | 说明 |
|------|-----------|------|
| 页面管理 | L2 PM · 页面管理 | 页面 CRUD、树形嵌套、侧边栏导航 |
| 块编辑器 | L2 PM · 块编辑器 | 多类型块的创建、编辑、排序 |
| 存储层 | L2 PM · 存储层 | SQLite 实现 + 接口抽象 |
| API 服务 | L2 PM · API 服务 | Go HTTP 服务 + RESTful 接口契约 |

## 模块详细需求

### 模块 A：页面管理

**场景矩阵**：

| 维度 | 场景 | 预期行为 |
|------|------|---------|
| 创建页面 | 在根目录创建页面 | 生成空白页面，出现在侧边栏 |
| 创建页面 | 在已有页面下创建子页面 | 子页面挂载到父页面，侧边栏树形展示 |
| 重命名 | 修改页面标题 | 侧边栏实时更新，URL 不变 |
| 删除页面 | 删除有子页面的页面 | 递归删除所有子页面，侧边栏移除 |
| 删除页面 | 删除空页面 | 直接删除，侧边栏移除 |
| 嵌套导航 | 展开/折叠侧边栏节点 | 显示/隐藏子页面列表 |
| 嵌套深度 | 无限层级嵌套 | 无层级上限限制 |

**验收标准**：
- [ ] 可创建根页面和子页面
- [ ] 侧边栏正确展示树形结构
- [ ] 删除父页面时递归删除子页面
- [ ] 页面重命名实时反映在侧边栏

### 模块 C：存储层

**设计要求**：
- Repository 接口抽象，隔离具体存储实现
- 一期实现：SQLite
- 接口设计需支持后期替换为 PostgreSQL 等

**数据模型**：

| 实体 | 核心字段 |
|------|---------|
| Page | id, title, parent_id, order, created_at, updated_at |
| Block | id, page_id, type, content(JSON), order, parent_block_id, created_at, updated_at |

**场景矩阵**：

| 维度 | 场景 | 预期行为 |
|------|------|---------|
| 接口抽象 | 替换存储实现 | 只需实现 Repository 接口，上层无感知 |
| 并发写入 | 多个块同时保存 | 数据一致，无丢失 |
| 数据迁移 | 新增字段 | 通过 migration 脚本升级，不破坏已有数据 |
| 数据文件 | 默认路径 | `~/.local/share/noteyard/noteyard.db` |

**验收标准**：
- [ ] Repository 接口定义完整，SQLite 实现通过单元测试
- [ ] 数据库初始化脚本可重复执行（幂等）
- [ ] migration 机制存在

### 模块 D：API 服务

**技术栈**：Go HTTP 服务，监听 `localhost:8080`

**核心接口**：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/pages` | 获取页面树 |
| POST | `/api/pages` | 创建页面 |
| GET | `/api/pages/:id` | 获取单页面（含块列表） |
| PUT | `/api/pages/:id` | 更新页面（标题/父级） |
| DELETE | `/api/pages/:id` | 删除页面（级联） |
| GET | `/api/pages/:id/blocks` | 获取页面块列表 |
| POST | `/api/pages/:id/blocks` | 创建块 |
| PUT | `/api/blocks/:id` | 更新块内容/顺序 |
| DELETE | `/api/blocks/:id` | 删除块 |

**场景矩阵**：

| 维度 | 场景 | 预期行为 |
|------|------|---------|
| 正常请求 | 合法参数 | 返回 200/201，正确数据 |
| 参数错误 | 缺少必填字段 | 返回 400，错误说明 |
| 不存在资源 | ID 不存在 | 返回 404 |
| 级联删除 | 删除有子页面的页面 | 递归删除，返回 200 |
| 跨域 | 前端 localhost:3000 访问 | CORS 正确配置 |

**验收标准**：
- [ ] 所有接口可正常响应
- [ ] 错误码规范统一
- [ ] CORS 配置允许前端访问
- [ ] 接口文档（README 或 OpenAPI）存在
