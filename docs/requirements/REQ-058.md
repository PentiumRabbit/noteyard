# REQ-058 全局 UI 样式统一优化

**状态**：草稿  
**日期**：2026-05-02  
**作者**：PM  
**范围**：仅改样式，不改功能逻辑，不引入新 JS 依赖

---

## 背景

数据库视图各弹层/面板样式各自为政，没有统一的基础 CSS class 供复用，导致视觉不一致，维护成本高。以下是最明显的 10 条问题：

| # | 问题 | 具体表现 |
|---|------|---------|
| 1 | **弹层阴影不统一** | `col-menu`/`formula-popover`/`rollup-popover`/`select-opts-popover` 使用三层 rgba 阴影；`select-dropdown`/`add-col-popover` 只有两层；`col-type-dropdown`/`files-cell-img-tooltip` 使用 `0 4px 16px rgba(0,0,0,.12)`；`db-panel` 仅 `0 0 0 1px, 0 2px 4px`；`row-modal` 用 4 层最深阴影。共 5 套写法。 |
| 2 | **弹层圆角不统一** | 大多数弹层 `border-radius: 6px`，但 `row-modal` 和 `relation-picker` 用 `8px`，单元格类控件用 `3px`/`4px`，没有明确分层规范。 |
| 3 | **弹层内边距不统一** | `col-menu` padding 为 `6px 4px`；`formula-popover`/`rollup-popover`/`select-opts-popover` 为 `12px`；`add-col-popover` 为 `10px`；`db-panel` 为 `10px 12px`。同级浮层内边距相差 20%～100%。 |
| 4 | **files-cell 存在两套重复定义** | `DatabaseView.css` 中 `files-cell`/`files-cell-del`/`files-cell-upload`/`files-cell-more` 等类各自出现两次（第一套在 L1229，第二套在 L1315），后者覆盖前者，且两套颜色规则不同，制造歧义。 |
| 5 | **FilesCell/FilesModal 大量硬编码颜色** | `files-cell-del`（背景 `#f0f0f0`、颜色 `#6b7280`），`files-cell-upload`（背景 `#e8f4fd`），`files-cell-more`（背景 `#f3f0ff`），`files-modal-item`（背景 `#f9f9f9`），`files-modal-upload-btn`（`#f0f7ff`/`#2383e2`），`files-modal-size`（`#9b9b9b`），`files-modal-empty`（`#c0c0c0`）均为硬编码，不随主题切换。 |
| 6 | **relation-tag 硬编码蓝色** | `.relation-tag` 使用 `background: #e8f4fd; color: #2383e2`，`.relation-tag-deleted` 使用 `#f0f0f0/#9b9b9b`，均未使用 CSS 变量，深色/暖色主题下颜色错误。 |
| 7 | **batch-bar 背景硬编码** | `.db-batch-bar` 使用 `background: #e8f0fe`，未使用 `var(--color-selected-bg)` 或变量，主题切换时外观不变。 |
| 8 | **page-cover-action-btn 硬编码白色** | `App.css` 中 `.page-cover-action-btn` 使用 `rgba(255,255,255,0.85)` 和 `color: #37352f`，深色主题下不可见。 |
| 9 | **操作按钮 font-size 散乱** | 面板内操作按钮字号：`formula-save-btn`/`formula-cancel-btn` 为 `12px`；`add-col-actions button` 为 `12px`；`db-batch-btn` 为 `12px`；但行操作按钮 `.row-open-btn` 图标字号为 `13px`；列菜单内 `col-menu-type-item` 为 `13px`。没有统一的"小按钮"基础类。 |
| 10 | **缺少 focus-visible 状态** | `db-toolbar-btn`、`db-view-btn`、`col-header-btn`、`add-col-actions button` 等均无 `:focus-visible` 样式，键盘可访问性不足。 |

## 设计目标

建立一套可复用的基础样式规范，覆盖以下四类：

### 1. Panel（内联面板，如筛选/排序/隐藏列）
```
border-radius: 6px
box-shadow: var(--shadow-sm)      /* 定义为: rgba(0,0,0,.1) 0 0 0 1px, rgba(0,0,0,.1) 0 2px 4px */
padding: 10px 12px
background: var(--color-bg-secondary)
border: 1px solid var(--color-border-medium)
```

### 2. Popover（浮动弹层，如列菜单/新增列/公式编辑器）
```
border-radius: 6px
box-shadow: var(--shadow-md)      /* 定义为: rgba(0,0,0,.1) 0 0 0 1px, rgba(0,0,0,.2) 0 3px 6px, rgba(0,0,0,.3) 0 9px 24px */
padding: 8px 6px
background: var(--color-bg-secondary)
border: 1px solid var(--color-border-medium)
```

### 3. Modal（居中全屏模态框，如行详情/关联选择器）
```
border-radius: 8px
box-shadow: var(--shadow-lg)      /* 定义为: rgba(0,0,0,.1) 0 0 0 1px, rgba(0,0,0,.2) 0 8px 24px, rgba(0,0,0,.4) 0 16px 56px */
background: var(--color-bg-secondary)
border: none
```

### 4. Button（操作按钮）
小尺寸（工具栏/面板内）：
```css
.db-btn-sm {
  padding: 4px 10px;
  border-radius: 4px;
  font-size: 12px;
  font-family: inherit;
  cursor: pointer;
  border: none;
}
.db-btn-sm-primary { background: var(--color-accent); color: #fff; }
.db-btn-sm-default { background: var(--color-hover-bg-medium); color: var(--color-text-primary); }
.db-btn-sm:focus-visible { outline: 2px solid var(--color-accent); outline-offset: 1px; }
```

同时新增阴影变量到 `index.css`：
```css
--shadow-sm: rgba(0,0,0,.1) 0 0 0 1px, rgba(0,0,0,.1) 0 2px 4px;
--shadow-md: rgba(0,0,0,.1) 0 0 0 1px, rgba(0,0,0,.2) 0 3px 6px, rgba(0,0,0,.3) 0 9px 24px;
--shadow-lg: rgba(0,0,0,.1) 0 0 0 1px, rgba(0,0,0,.2) 0 8px 24px, rgba(0,0,0,.4) 0 16px 56px;
```

新增主题感知颜色变量到 `index.css`（含深色/暖色版本）：
```css
--color-tag-relation-bg: #e8f4fd;
--color-tag-relation-text: #2383e2;
--color-tag-deleted-bg: var(--color-hover-bg-medium);
--color-tag-deleted-text: var(--color-text-secondary);
--color-batch-bar-bg: rgba(35,131,226,0.08);
```

## 验收标准

1. **主题一致性**：在 light / dark / warm 三个主题下，所有弹层（col-menu、formula-popover、add-col-popover、select-dropdown、row-modal、relation-picker、db-panel）的背景色、边框、阴影均来自 CSS 变量，无硬编码 hex 颜色（files 附件系列除外，仅允许 `var(--color-*)` 形式的 fallback）。

2. **阴影层级语义**：panel（内联）使用 `var(--shadow-sm)`，popover（浮动）使用 `var(--shadow-md)`，modal（居中）使用 `var(--shadow-lg)`，无混用。

3. **无重复定义**：`DatabaseView.css` 中 `.files-cell` 及其子类只存在一套定义。

4. **focus-visible 覆盖**：用 Tab 键可见焦点环出现在所有工具栏按钮、视图切换按钮、弹层操作按钮上。

5. **功能无回归**：所有现有数据库视图功能（表格/看板/画廊/列表/日历/时间轴）不受影响，E2E 测试全绿。

6. **无新 JS 依赖**：`package.json` 中无新增条目。
