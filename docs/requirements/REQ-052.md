# REQ-052 Columns 块架构迁移至 BlockNote 原生 columnList/column

| 字段 | 内容 |
|------|------|
| REQ ID | REQ-052 |
| 类型 | 技术债/架构重构 |
| 优先级 | P2 |
| 状态 | 待排期 |
| 来源 | ISS-002 技术债 + ISS-003 根本原因 |

## 背景

当前 `ColumnsBlock` 使用嵌套 mini-editor（每列一个独立 BlockNote 实例）的方案存在结构性缺陷：
- 列内状态游离于主编辑器文档树之外
- undo/redo、协作、schema 同步需手动维护
- ISS-002/ISS-003 崩溃的根本原因均源于此设计

## 目标

迁移至 BlockNote 原生 `columnList`/`column` 块类型，列内容成为主文档树的一部分，所有能力自动继承。

## 已知风险

- BlockNote 0.26 columnList/column API 文档不完整，存在兼容性风险
- 历史 `columnsData` JSON prop 数据需迁移为 children 结构
- 改动面广：Editor.tsx + toBlockNote.ts + 后端 children 结构支持
