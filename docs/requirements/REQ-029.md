## 用户故事

作为 noteyard 用户，我希望能在编辑器中插入和操作数据库表格块，以便在页面内直接管理结构化数据。

---

## 一期范围

承接 REQ-028 后端数据层，本期交付前端编辑器集成。

---

## 功能范围

- 编辑器内可插入 database 块（`/database` 触发）
- 表格视图：显示列头 + 行数据，支持行内编辑
- 列管理：添加列、修改列名/类型、删除列
- 行管理：添加行、删除行
- formula 列：只读显示计算结果
- 单元格编辑：根据列类型渲染不同控件（text/number/checkbox/select/date）

## 不在本期范围

- 看板视图、日历视图
- 列宽调整、列排序
- 行筛选、排序

---

## 场景矩阵

| 维度 | 场景 | 预期行为 |
|------|------|---------|
| 插入块 | `/database` 触发 | 创建空 database，渲染表格骨架 |
| 添加列 | 点击"添加列"按钮 | 弹出列类型选择，写入后刷新列头 |
| 添加列 | formula 列循环引用 | 后端拒绝，前端展示错误提示 |
| 编辑单元格 | text/number 列 | 点击进入编辑，失焦保存 |
| 编辑单元格 | checkbox 列 | 点击切换，即时保存 |
| 编辑单元格 | select 列 | 点击展开选项，选中保存 |
| 编辑单元格 | date 列 | 点击展开日期选择器，选中保存 |
| formula 列 | 显示计算结果 | 只读，值来自后端 GET rows |
| 添加行 | 点击"添加行"按钮 | 新行插入，所有 cell 为空 |
| 删除行 | 行操作菜单 | 确认后删除，表格移除该行 |
| 删除列 | 列操作菜单 | 确认后删除，列头和所有 cell 消失 |
| 空 database | 无列无行 | 展示引导提示"添加第一列" |
| 数量边界 | 大量行（50+） | 正常渲染，无性能崩溃 |
