## 用户故事

作为 noteyard 数据库用户，我希望公式列支持 IF、CONCAT、ROUND 等常用函数，以便在数据库中完成条件判断、字符串拼接、数值格式化等复合计算，无需导出到外部工具处理。

---

## 当前支持的语法

公式列目前支持以下语法：

- **属性引用**：`prop("列名")` — 引用同行其他列的值
- **四则运算**：`+`、`-`、`*`、`/` — 对数值型属性进行算术计算
- **括号分组**：`(expr)` — 控制运算优先级

**示例**：
```
prop("单价") * prop("数量")
(prop("收入") - prop("成本")) / prop("收入")
```

不支持任何函数调用、条件分支或字符串操作。

## 新增函数清单

### P1 — 核心函数（本期必须实现）

| 函数签名 | 说明 | 返回类型 |
|---------|------|---------|
| `IF(condition, then, else)` | 条件判断，condition 为真返回 then，否则返回 else | 任意 |
| `CONCAT(a, b, ...)` | 将多个字符串或值拼接为一个字符串 | 文本 |
| `ROUND(n, digits)` | 将数值 n 四舍五入到 digits 位小数 | 数值 |
| `ABS(n)` | 返回数值 n 的绝对值 | 数值 |
| `NOT(bool)` | 对布尔值取反 | 布尔 |

### P2 — 扩展函数（下期迭代）

| 函数签名 | 说明 | 返回类型 |
|---------|------|---------|
| `SUM(prop1, prop2, ...)` | 对多个数值属性求和 | 数值 |
| `MIN(a, b, ...)` | 返回多个值中的最小值 | 数值 |
| `MAX(a, b, ...)` | 返回多个值中的最大值 | 数值 |
| `LEN(str)` | 返回字符串的字符长度 | 数值 |
| `FLOOR(n)` | 向下取整 | 数值 |
| `CEIL(n)` | 向上取整 | 数值 |

### P3 — 高级函数（后续规划）

| 函数签名 | 说明 | 返回类型 |
|---------|------|---------|
| `DATE_FORMAT(date, fmt)` | 将日期格式化为指定字符串 | 文本 |
| `CONTAINS(str, substr)` | 判断字符串是否包含子串 | 布尔 |
| `REPLACE(str, old, new)` | 替换字符串中的子串 | 文本 |
| `UPPER(str)` | 转换为大写 | 文本 |
| `LOWER(str)` | 转换为小写 | 文本 |

## 场景矩阵

| # | 场景 | 公式示例 | 预期结果 |
|---|------|---------|---------|
| 1 | IF — 任务状态标记 | `IF(prop("完成度") >= 100, "已完成", "进行中")` | 完成度 ≥ 100 的行显示"已完成"，其余显示"进行中" |
| 2 | IF — 价格区间分类 | `IF(prop("单价") > 500, "高端", IF(prop("单价") > 100, "中端", "低端"))` | 嵌套 IF 正确分层分类 |
| 3 | CONCAT — 姓名拼接 | `CONCAT(prop("姓"), prop("名"))` | 姓名列合并为单个字符串，如"张三" |
| 4 | CONCAT — 带分隔符拼接 | `CONCAT(prop("城市"), " · ", prop("地区"))` | 输出如"北京 · 朝阳" |
| 5 | ROUND — 百分比格式化 | `ROUND(prop("完成度") / prop("目标") * 100, 1)` | 保留一位小数，如 87.5 |
| 6 | ABS — 差值计算 | `ABS(prop("预算") - prop("实际"))` | 无论正负偏差均返回正数 |
| 7 | NOT — 待办标记取反 | `NOT(prop("已完成"))` | 布尔列取反，"已完成"为 false 时显示 true |
| 8 | IF + ABS 组合 | `IF(ABS(prop("偏差")) > 10, "超出预算", "正常")` | 函数嵌套调用正确求值 |

## 验收标准

- [ ] 公式编辑器支持输入函数名并给出自动补全提示
- [ ] P1 五个函数（IF、CONCAT、ROUND、ABS、NOT）全部可用，计算结果正确
- [ ] IF 支持至少两层嵌套
- [ ] CONCAT 支持 2 个及以上参数
- [ ] ROUND 的 digits 参数支持 0 ～ 10 整数
- [ ] 公式语法错误时，单元格显示明确的错误提示（如 `#ERROR`），不崩溃
- [ ] 引用不存在的列时，给出"列名不存在"提示
- [ ] 函数名大小写不敏感（`if` 与 `IF` 等效）
- [ ] 现有 prop + 四则运算公式不受影响，向后兼容
