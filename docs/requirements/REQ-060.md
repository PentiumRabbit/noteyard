## 背景

noteyard 是本地版 Notion 替代品（Go + SQLite + React + BlockNote），目前仅在私有仓库开发，未对外发布。

为使项目可以开源并吸引社区贡献，需要完成以下工作：

1. **Tauri 桌面客户端**：将现有 web 前端 + Go server 打包为跨平台本地桌面应用，让用户无需部署服务器即可一键运行。
2. **GitHub 社区配置**：添加 Issue 模板、PR 模板、CONTRIBUTING.md、LICENSE、CODE_OF_CONDUCT.md，为社区贡献建立标准流程。
3. **GitHub Actions CI**：自动化构建与测试，保障代码质量。
4. **README.md**：项目主页文档，介绍功能、截图、安装方式和技术栈。

## 功能范围

### F1 — Tauri 桌面客户端（sidecar 方式）

使用 Tauri v2 将前端 web 资源与 Go server 二进制打包为单一桌面应用程序。

**技术约束：**
- Tauri 版本：**v2**（`@tauri-apps/cli` v2.x、`tauri` crate v2.x）
- Go server 以 **sidecar** 方式嵌入：Tauri 在启动时自动启动后台 Go 进程，关闭时终止
- sidecar 二进制命名规范：遵循 Tauri v2 sidecar 命名约定（含平台三元组后缀，如 `noteyard-server-x86_64-apple-darwin`）
- Go server 监听端口：**8080**（localhost only，不暴露外网）
- 前端 web 以 **embedded** 方式内嵌（`devUrl` 在开发时指向 Vite dev server，生产构建使用 `distDir` 内嵌静态文件）
- 前端通过 `http://localhost:8080` 调用 Go server API（与现有 web 部署方式一致，无需改动 API 层）
- 打包目标平台：**macOS**（Apple Silicon + Intel）、**Windows**（x64）、**Linux**（x64 AppImage + deb）
- Tauri 项目目录：`src-tauri/`（位于项目根目录）
- 构建命令：`pnpm tauri build`（开发命令：`pnpm tauri dev`）

**文件新增清单：**

| 文件路径 | 说明 |
|---------|------|
| `src-tauri/Cargo.toml` | Tauri v2 依赖声明 |
| `src-tauri/tauri.conf.json` | Tauri 配置（窗口、sidecar、bundle identifier 等） |
| `src-tauri/src/main.rs` | Tauri 应用入口（启动 sidecar + WebviewWindow） |
| `src-tauri/src/lib.rs` | Tauri app 构建逻辑（供 main.rs 调用） |
| `src-tauri/build.rs` | Tauri build script（必须存在） |
| `src-tauri/capabilities/default.json` | Tauri v2 capabilities 配置（sidecar 权限声明） |
| `src-tauri/icons/` | 应用图标（各尺寸 PNG + .icns + .ico，使用占位图） |

**tauri.conf.json 关键配置要求：**
- `bundle.identifier`：`com.noteyard.app`
- `bundle.targets`：`["dmg","msi","deb","appimage","nsis"]`（各平台按需）
- `app.windows[0].title`：`"noteyard"`
- `app.windows[0].width` / `height`：`1280` / `800`
- `plugins.shell.open`：启用（用于外部链接）
- sidecar 声明在 `bundle.externalBin` 中，路径：`"binaries/noteyard-server"`
- capabilities 中声明 `shell:allow-spawn`（sidecar 启动权限）

**main.rs 逻辑要求：**
- 应用启动时使用 `tauri_plugin_shell::process::CommandChild` 启动 sidecar
- sidecar 进程存储在全局 `Mutex<Option<CommandChild>>` 中
- 应用退出时（`on_window_event` / `RunEvent::Exit`）终止 sidecar 进程
- 开发模式下不启动 sidecar（通过 `cfg!(dev)` 判断，开发时 Go server 由 `make dev` 单独启动）

**Go server 构建适配：**
- Go server 需支持交叉编译为目标平台二进制（`GOOS`/`GOARCH` 环境变量）
- 二进制输出路径：`src-tauri/binaries/noteyard-server-<target-triple>`
- 构建脚本（`Makefile` 或 `scripts/build-sidecar.sh`）负责编译并将二进制复制到正确路径

### F3 — GitHub Actions CI

**文件新增清单：**

| 文件路径 | 说明 |
|---------|------|
| `.github/workflows/ci.yml` | CI workflow（构建 + 测试） |

**CI workflow 要求：**

触发条件：
- `push` 到 `main` 分支
- `pull_request` 目标分支为 `main`

Job 拆分：

| Job 名称 | 运行环境 | 职责 |
|---------|---------|------|
| `backend` | `ubuntu-latest` | Go 格式检查（`gofmt`）+ 编译（`go build ./...`）+ 测试（`go test ./...`） |
| `frontend` | `ubuntu-latest` | 安装依赖（`npm ci`）+ TypeScript 类型检查（`tsc --noEmit`）+ 构建（`npm run build`） |

依赖缓存：
- Go：使用 `actions/setup-go@v5` 内置缓存（`cache: true`）
- Node：使用 `actions/setup-node@v4` + `cache: 'npm'`（工作目录 `web/`）

Action 版本（固定版本，不用 `latest`）：
- `actions/checkout@v4`
- `actions/setup-go@v5`
- `actions/setup-node@v4`
