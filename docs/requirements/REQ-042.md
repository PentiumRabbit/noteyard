## 更新范围

### 需新增内容

**快速开始页**：
- 提及设置面板（字体/主题）入口

**编辑器块类型页**：
- 补充图片块：粘贴或拖拽图片自动上传，显示在编辑器中
- 补充格式化工具栏：选中文字后弹出，支持加粗/斜体/下划线/行内代码/颜色/对齐

**新增「个性化设置」说明**（在快速开始页或独立小节）：
- 字体切换：侧边栏底部 ⚙ 按钮 → 字体区域，11 种可选，网络字体需联网加载
- 主题切换：同入口 → 主题区域，5 套主题，网络主题需联网加载
- 偏好自动保存，下次启动恢复

**斜杠菜单**：
- 说明支持中文拼音模糊匹配（如输入 `biaoge` 或 `bg` 匹配「表格」）

**数据库功能页**：
- 公式列描述更正：支持 IF、CONCAT、ROUND、ABS、NOT、AND、OR、LEN、UPPER、LOWER、TRIM、比较运算符等

### 需更正内容

**已知限制页**：
- 删除「公式列支持四则运算，复杂表达式（如 IF/SUM）暂不支持」→ 改为当前实际限制
