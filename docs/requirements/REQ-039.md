## 用户故事

作为 noteyard 用户，我希望能切换编辑器字体和视觉主题，设置在刷新后自动恢复，选中网络资源时自动下载并生效，断网时降级到本地默认。

---

## 核心架构：统一资源配置系统

字体和主题本质上是同一类问题——「把一个外观资源应用到编辑器」。本需求将两者统一为**资源配置系统**，共用同一套数据结构、加载器和生效机制。

### 资源条目结构

```ts
interface ResourceEntry {
  id: string;           // 唯一标识，如 "noto-sans-sc"、"aurora"
  name: string;         // 显示名称，如 "思源黑体"、"极光"
  type: "local" | "remote";
  url?: string;         // remote 类型必填，CSS 文件或字体 CSS 的 CDN 地址
  applyMethod: "css-var" | "data-theme"; // 字体 → css-var；主题 → data-theme
}
```

### 通用资源加载器行为

1. 本地资源：直接应用（更新 CSS 变量或切换 `data-theme`），无需网络请求，即时生效。
2. 远程资源（首次）：动态插入 `<link rel="stylesheet">` → 监听 `onload` / `onerror` → 加载中展示视觉反馈 → 加载成功后执行生效操作。
3. 远程资源（已缓存）：`<link>` 标签已存在于 DOM，直接执行生效操作，无重复请求。
4. 断网 / 加载失败：降级到对应类型的本地默认资源，展示友好提示。

### 生效机制

| 资源类型 | 生效方式 | 示例 |
|---------|---------|------|
| 字体 | 更新 `--font-body` CSS 变量 | `document.documentElement.style.setProperty('--font-body', '"Noto Sans SC", sans-serif')` |
| 主题 | 切换 `<html>` 的 `data-theme` 属性 | `document.documentElement.setAttribute('data-theme', 'aurora')` |

### 持久化

- 字体偏好写入 `localStorage`（key: `noteyard_font`），默认值 `default-sans`。
- 主题偏好写入 `localStorage`（key: `noteyard_theme`），默认值 `default-light`。
- 应用启动时优先读取两个值，无记录则使用默认。

### 可扩展性

后续新增字体或主题，只需在配置文件中追加 `ResourceEntry` 条目，加载逻辑和生效逻辑无需修改。

## 字体预置清单

### 本地字体（3 档，即时切换）

| ID | 显示名称 | 字体栈 | 说明 |
|----|---------|--------|------|
| `default-sans` | Default Sans | `ui-sans-serif, -apple-system, BlinkMacSystemFont, "Segoe UI", Helvetica, Arial, sans-serif` | 系统无衬线，当前默认 |
| `serif` | Serif | `ui-serif, Georgia, "Times New Roman", Times, serif` | 系统衬线，适合长文阅读 |
| `mono` | Mono | `ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace` | 系统等宽，适合技术笔记 |

## 主题预置清单

### 本地主题（3 套，即时切换）

| ID | 显示名称 | 色调描述 |
|----|---------|---------|
| `default-light` | 默认亮色（Default Light） | 白色背景，深灰文字，Notion 经典风格，高对比度 |
| `dark` | 暗色（Dark） | 深灰/近黑背景，浅灰文字，护眼，类 Notion Dark |
| `warm` | 暖米色（Warm） | 米黄/奶油色背景，棕灰文字，纸张质感，适合长文写作 |

### 网络主题（2 套，选中后按需加载）

| ID | 显示名称 | 色调描述 |
|----|---------|---------|
| `aurora` | 极光（Aurora） | 深紫渐变背景，霓虹青/紫强调色，赛博朋克风格 |
| `forest` | 森林（Forest） | 深绿色系背景，自然橄榄/苔绿调，沉静自然感 |

> 主题 CSS 变量体系核心属性：`--color-bg-primary`、`--color-bg-secondary`、`--color-text-primary`、`--color-text-secondary`、`--color-accent`、`--color-border`、`--color-surface`。本地主题切换时包含颜色过渡动画（`transition: background-color 0.2s, color 0.2s`）。

## 验收标准

**资源系统层面**
- [ ] 字体和主题共用统一的资源条目结构（`ResourceEntry`）和加载器逻辑
- [ ] 新增资源只需在配置文件添加条目，不改动加载或生效逻辑

**字体**
- [ ] 3 种本地字体均可选择，切换后编辑器正文（段落、标题、列表、引用等）立即重新渲染
- [ ] 代码块字体始终保持 Mono，不受全局字体影响
- [ ] 8 种网络字体选中后动态加载，加载中有视觉反馈
- [ ] 字体加载完成后自动切换，无需额外操作
- [ ] 网络字体选项有明确的「需联网」标注
- [ ] 断网时选择网络字体降级到默认字体，显示友好提示
- [ ] 字体偏好持久化到 `localStorage`（key: `noteyard_font`），刷新后自动恢复

**主题**
- [ ] 5 套主题均可在主题选择面板中展示并选中
- [ ] 3 种本地主题切换即时生效，包含颜色过渡动画（≤ 200ms）
- [ ] 2 种网络主题联网时可正常加载并切换
- [ ] 网络主题选项显示「需联网」标识
- [ ] 断网时选择网络主题降级为默认亮色，显示失败提示
- [ ] 主题偏好持久化到 `localStorage`（key: `noteyard_theme`），刷新后自动恢复
- [ ] 无 localStorage 记录时默认使用 `default-light`
- [ ] 编辑器、侧边栏、弹窗、数据库视图等所有区域均响应主题变量

**通用**
- [ ] 本地资源即时切换，远程资源选中才下载，已加载资源同会话内不重复请求
- [ ] 所有页面共享同一字体和主题设置，非单页独立配置
